# Optional table and cell properties

Status: implementation contract; actual validation belongs to verification-backlog.md.

## Scope and public API

Expose `/plugins/table-properties` with `tableProperties()`, `tablePropertyCommands(editor)` and feature-owned types. Install `tables()` first. This explicit opt-in headless module has no runtime dependencies or preset installation; its form is independently imported. The original style slice excludes header/caption conversion; the additive [table-headers-caption.md](table-headers-caption.md) contract now adds that behavior below. The later [table-row-height.md](table-row-height.md) slice adds minimum row height through the same optional module. Border width/style, padding and Office compatibility remain outside these slices.

`TablePropertiesPatch` accepts only these optional own fields:

The original five style fields are listed here. The additive header/caption slice also accepts `headerRow?: boolean`, `headerColumn?: boolean`, `caption?: string | false` under its stricter structural contract. Undefined/unknown fields remain invalid.

- `width: string | false`: canonical integer `40–4000px` or `1–100%`; false removes owned CSS width and the legacy TABLE width attribute. Any width write removes that attribute to avoid competing fallback values.
- `alignment: TableAlignment | false`, where the enum is left/center/right. Physical TABLE placement uses margin-left/right pairs: left `0px/auto`, center `auto/auto`, right `auto/0px`. False removes both declarations. This is not text alignment; at 100% width the placement may be visually neutral.
- `cellBackground: string | false` and `cellBorder: string | false`: one bounded safe color (at most 100 characters), using the existing color grammar (hex, named, numeric rgb/rgba/hsl/hsla) plus browser color parsing; no URLs, var(), escapes, CSS-wide keywords (inherit/initial/unset/revert), functions outside that list, declarations, !important or arbitrary CSS. False removes only the corresponding own color declaration. Return browser-canonical explicit values.
- `cellVerticalAlign: TableCellVerticalAlign | false`, where the enum is top/middle/bottom. False removes only vertical-align.

`TablePropertiesCommands.update(patch): void` snapshots and validates the complete patch before eligibility/mutation, including unknown keys, explicit undefined, arrays and unsupported values. Empty/idempotent patches preserve redo and pending formatting. One patch is one validated atomic command/history operation, even when changing table and many cells together. The module does not explicitly focus; the existing SDK transaction may focus the editor. Bind its private request to the original actual region and revalidate after that focus before mutation. Keep actual table/cell/content nodes and the native/private logical selection; do not clone or rebuild content to style it.

`getState(): TablePropertiesState` is side-effect free and returns `disabled`, `width`, `alignment`, `cellBackground`, `cellBorder`, and `cellVerticalAlign`. Missing explicit values are false. Cell values use the literal `mixed` if selected cells differ. Imported safe CSS width units outside the command's narrower integer px/% choices are reported as stored strings; unrelated property updates do not rewrite them. Width reads CSS first, then legacy numeric TABLE width as px. Alignment false may indicate no recognized canonical margin pair; reset must still remove present margins. Values describe inline persisted data, not computed theme CSS.

The additive state also includes headerRow/headerColumn booleans and caption string|false. Header operations address the first logical row/column of the whole selected table, not only selected cells. They convert TD/TH wrappers while preserving actual content nodes, spans, row/table identity, selection and history; wrapper identity necessarily changes on retag. Caption is direct native CAPTION, bounded literal text <=5000, with same-text rich-child preservation and false/empty removal. Crossing header/body merged cells reject the entire combined patch before any styling. See table-headers-caption.md for inference, minimum dimensions, corner priority, focus checks and duplicate-caption limitations; existing persisted TH/scope/CAPTION need no schema change. These later browser definitions are authored, not locally executed in the current user-requested mode.

## Authority, lifecycle and atomicity

Reuse the selective `getTableSelection` projection and tables' actual private logical selection, not spoofable data attributes. A native range must belong to one actual cell; explicit merged-cell rectangles must form a complete valid bounded grid in one connected ordinary table. Reject nested/foreign/semantic/protected tables or ancestors/descendants, holes/overlap and ambiguous/cross-cell native ranges. Add protected-content checks because the existing table projection does not by itself cover contenteditable=false descendants.

The command registry supplies transaction, read-only and core composition gates. Public invalid payloads throw before eligibility; missing/stale/unsupported targets are inert. Revalidate authority in execution. Plugin state is per editor; unregister provided API/command on disposal, and retained commands fail after disposal. No listener, event bus, document-global state or extra DOM registry is required for the headless module.

## Persisted style boundary

Keep schema version 1 with a narrow additive codec extension only: TABLE margin-left/right accept `0px | auto`; TD/TH vertical-align accepts `top | middle | bottom`. Other tags/values discard these styles through the existing HTML/JSON style filter. CSS-wide values, percentages/lengths on these margins, arbitrary margin shorthand, baseline/length vertical alignment and declaration injection do not survive. Existing safe width/background/border style support is unchanged. Use both HTML and JSON acceptance and malicious-style regressions. Older readers may discard the new styles; schema-v1 does not mean lossless older-reader support.

HTML/JSON full-document roundtrip persists table and cell properties without this optional plugin installed. Existing rectangle clipboard creates a fresh TABLE: selected cell properties survive its cloned cells, but table width/alignment are not copied, even for an all-cells rectangle. Grid structural operations keep surviving actual cells/styles; inserted/split cells get their existing defaults and merge keeps the origin cell's styling. Do not silently expand those contracts.

## Reusable form

Expose independent `/ui/table-properties` with `createTablePropertiesForm(host, editor, options?)`, `tablePropertiesFormMessages`, and feature-owned controller/value/options/message-key types. No import from default standard/contextual UI or presets. Use explicit existing `/ui/forms.css`; add a separate CSS entry only if essential, and report it.

`TablePropertiesFormOptions` contains optional text `label` and diagnostic `onError(error): void | Promise<void>`. `TablePropertiesFormValues` contains string width/alignment/cellBackground/cellBorder/cellVerticalAlign. Controller exposes element, refresh(), getValues(), setValues(partial), destroy(). Invalid options/values reject before changes; get/set values snapshot. setValues marks supplied fields dirty without editing the document. Values use empty string for reset; mixed values use empty controls with a localized Mixed placeholder. Only dirty fields participate in Apply, so changing width never overwrites mixed cell styles or imported custom widths. Successful Apply resets drafts from authoritative state. Locale/readonly refresh preserves a draft while the same target is owned; switching target/API replacement discards stale drafts and authority.

The header/caption addition extends form values/getValues snapshots with headerRow/headerColumn/caption strings. Header selects are empty/off or "true"/on with localized No/Yes labels; the caption textarea accepts <=5000 UTF-16 units and preserves literal whitespace/newlines. Enter in that textarea inserts a line without submitting; use Apply. Dirty-only patching converts header drafts to booleans and empty caption to false, without trimming other caption text. Exact source fixtures must include the additive fields; public paths remain unchanged.

Mount into an empty connected external HTML host in the editor's document, outside persisted content. Register and clean up the table selection host. Capture an ordinary native cell range and actual table/cells/rectangle/revision while the editor owns focus; keep that target while the form owns focus. External replacement, read-only/composition, stale table/cell identities, selection changes in another table, disposal and focus-time mutations cannot apply a draft to a different target. Use the shared selection restore with an owned post-focus/pre-restore acceptance guard: reject actual native target changes before overwriting the Range, then recheck the restored region before update. Existing forms without that optional internal guard retain their behavior. Follow existing per-editor form/contextual target-identity patterns without importing contextual UI implementation. Preserve backward native ranges where supported. No image/content clones, remote resources, previews or uploads.

Native labeled controls expose width text, table-alignment select, background/border text colors and vertical-alignment select. One Apply button; localized label/field names/status/mixed/reset options in RU/EN and text overrides. Plain Enter applies from inputs; IME/229 Enter must not submit. Buttons/fields disabled without eligible target or during readonly/composition. Synthetic clicks/retained callbacks cannot bypass guards. Error callbacks cannot leak rejections or prevent cleanup. Dispose all DOM listeners/subscriptions/owned DOM, idempotently; editor destruction cleans up automatically.

## Validation, packaging and weight

Use representative Chromium/Firefox/WebKit cases for atomic mixed table/cell patch and exact Undo/Redo/selection; spans and unchanged actual cells; mixed/reset/noop; readonly/IME/API replacement/disposal; invalid whole patch and unsupported/protected/foreign/nested/grid/range sources. Codec tests cover supported/unsupported tags/values, HTML/JSON/no-plugin roundtrip, injection/no resource loading, and selected rectangle clipboard versus full-table metadata limits. Form tests exercise real focus restoration/target race, draft dirtiness/locale/mixed state, keyboard/read-only, multiple editors and cleanup. Adapter consumers verify controlled feedback and lifecycle rather than replaying all command cases. RU/EN examples use public imports and actual controls, including narrow viewport.

Measure the headless entry under 15000 gzip JS bytes and the form entry under 20000 gzip JS bytes. The form guard covers its complete shipped dependency closure, including shared table/query/property code: the first build measured about 15000 bytes before final UI corrections, whereas adding plugin+form to the existing standard profile cost about 4750 gzip bytes. Keep useful implementation reserve rather than optimizing a handful of bytes against an unmeasured draft guard; selected-profile accounting remains the product-level check. Measure both entries and selected standard-properties-ready (plugin+form) under the current standard profile guard, preserving all other budgets. Report minified JS, gzip, Brotli and CSS separately, shared chunks once. No additional dependencies or framework runtimes; core contains only the bounded persistence change. Build/static/tree-shaking/package/consumer checks, final fresh-server browser and built-site verification must be recorded from actual runs; the spec itself does not claim passes.

## Minimum row height addition

The [table-row-height.md](table-row-height.md) contract adds validated rowMinHeight string|false patch input, string|false|mixed state, and a localized string form draft. Native TR height acts as a minimum; all actual rows intersecting the authoritative selected rectangle (including full rowspan) are targeted once. Existing height codec support retains HTML/JSON without a schema/allowlist expansion. Structural grid commands rebuild row wrappers and do not retain row height; rectangle clipboard omits it. Actual test/build/size evidence belongs to verification-backlog.md, not this contract.
