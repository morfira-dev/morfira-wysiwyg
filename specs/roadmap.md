# Product roadmap

The target is a capable lightweight editor for everyday authoring, implemented independently in strict TypeScript under MIT. Feature-for-feature parity with heavyweight editors and office suites is not the goal. Essential plugins ship ready to use, with selective imports and tree-shaking; applications can add their own plugins. Heavy processing is outside core and is not planned without a concrete requested use case. Core/plugins keep zero runtime dependencies; adapters use optional framework peers. Each milestone follows specification → implementation → browser acceptance → size measurement → RU/EN documentation. These milestones are development priorities, not release dates or claims of feature parity.

1. **Table clipboard and correctness — implemented baseline.** HTML/TSV ranges, copy/cut, merged-cell boundaries, bounded grid growth, atomic history. Contract: `specs/table-clipboard.md`.
2. **Everyday editing — lists, colors and link editing implemented.** Lists/nesting, block-boundary Enter/Backspace, links, alignment/colors, clear formatting, and usable toolbar controls. Lists/toolbar contract: `specs/lists-toolbar.md`; lists/toolbar are implemented; colors/link commands and forms are implemented; contract: `specs/colors-links.md`.
3. **Images — implemented.** Insertion dialog, application-owned upload callback, dimensions, captions, alt text, error handling. Contract: `specs/images.md`.
4. **Optional extensions — find/replace and statistics implemented; Markdown shortcuts implemented; mentions/slash editable-text and structural action phases implemented.** Find/replace (`specs/search.md`), statistics (`specs/statistics.md`) and Markdown shortcuts (`specs/markdown-shortcuts.md`) first; mentions/slash commands after the essential document flows (phase-1 contract: `specs/mentions-slash.md`; persistent atoms remain future).
5. **Extension architecture — implemented.** Typed per-instance core/plugin events, composable synchronous transactions, feature-owned types/folders and tested selective public imports. Contracts: `specs/events.md`, `specs/transactions.md`, `specs/code-organization.md`, `specs/modularity.md`.
6. **Product integration — tooling implemented.** Isolated tarball installation and Vue/React/Svelte production consumer checks; observational large-document/history benchmarks. Contracts: `specs/package-consumers.md`, `specs/performance.md`. Measured HTML snapshot reuse, local paragraph/heading inline formatting and current-run statistics reuse follow `specs/html-snapshots.md`, `specs/local-formatting.md` and `specs/statistics.md`. React layout-phase controlled feedback follows `specs/adapters-react-feedback.md`. Real-device IME/mobile/touch/accessibility checks remain unverified.

7. **Input stabilization — implemented bounded contracts.** Composition history/event ordering, external-value/read-only cancellation and candidate-confirmation guards follow `specs/composition.md`. Ordinary paragraph/heading splits, joins and structural barriers follow `specs/block-boundaries.md`. Controlled event sequences and desktop keyboard tests do not certify real OS IME or mobile keyboards. Cross-block replacement normalization remains future work.

The baseline already includes a versioned document model, formatting/selection/history, table grid and operations, three adapters, theming and local bilingual docs. Passing baseline tests does not establish arbitrary Word/Excel compatibility or production readiness.
