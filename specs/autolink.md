# Optional autolink — native Space completion

Status: phase 1 implementation contract. Original strict TypeScript/MIT, zero runtime dependencies, no core import edge to this plugin. Public facade entry is `/plugins/autolink`; no CSS or UI is required.

`autolink(options?: AutolinkOptions)` accepts `enabled?: boolean` (default true); copy and validate configuration before installation. `autolinkCommands(editor)` returns instance-owned `getState(): { enabled: boolean }` and `setEnabled(boolean)`. State changes are preferences only, including in read-only. Commands after disposal throw; disposal releases all listeners and plugin API ownership. Reusing one factory result in different editors must keep state isolated. Imports and factory creation are SSR-safe.

On a real native `input` event with `inputType: insertText` and data exactly one ASCII space, after core has recorded input, inspect only a bounded suffix (at most 2050 UTF-16 units) of the current paragraph/heading/list-item/blockquote/cell flow. A collapsed caret and trailing space/NBSP are required. Recognize completed case-insensitive `http://`, `https://` and `www.` tokens, up to 2048 UTF-16 units. Add `https://` to www links; validate through the platform URL parser and existing core link validation. Do not contact URLs or fetch previews. Leading whitespace/opening parentheses/brackets/braces may delimit a URL. Keep terminal sentence punctuation and unmatched closing parentheses/brackets/braces outside the anchor; balanced URL path delimiters remain inside. Unsupported protocols, quotes/angle delimiters, invalid hosts and truncated token beginnings stay literal.

Never cross block, line-break, image, code, existing anchor or inline semantic-node boundaries. Do not reinterpret tokens inside anchors, pre/code, figures/captions or inline semantic wrappers. Callout/block semantic metadata and surrounding inline formatting must survive conversion. Do not convert noncollapsed selections, read-only edits, IME composition, multi-character input, native paste/drop/history input or programmatic HTML/JSON replacement. Enter is deliberately not a trigger in phase 1: its structural empty-block caret requires the later SDK selection contract. Native paragraph splitting remains untouched. Pasted/imported URLs stay literal until ordinary completion input is typed.

Conversion uses an atomic transaction and existing safe link commands, then restores the original post-space caret. It does not rewrite text or insert HTML strings. The preceding native text/space revision and the conversion are distinct history operations. One undo removes automatic linking and restores the literal URL including its typed space; redo restores the link and caret. Subsequent input stays outside the anchor. One conversion produces one additional user-change event. Core input and optional Markdown shortcuts remain independent.

Acceptance Chromium/Firefox/WebKit: real typing of http/https/www; sentence and balanced punctuation; rich inline content and semantic callout metadata; one-conversion undo/redo plus actual next typing; excluded contexts and URL protocols; read-only/composition/selection/paste/external boundaries; bounded long paragraphs; preference updates, two instances, cleanup and SSR. Verify built public facade imports, type declarations, zero runtime dependencies, selective imports and raw/gzip/Brotli module size. RU/EN docs must state the Space-only trigger and post-space undo behavior explicitly.
