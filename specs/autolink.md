# Optional autolink — Space, controlled Enter and plain URL paste

The independent opt-in `AutolinkOptions.email` extension follows
[autolink-email.md](autolink-email.md). It defaults to false, is forwarded by
standard/extended preset options and does not broaden the completion routes below.

Status: bounded completion implementation contract; current validation is recorded separately. Original strict TypeScript/MIT, zero runtime dependencies, no core import edge to this plugin. Public facade entry is `/plugins/autolink`; no CSS or UI is required.

`autolink(options?: AutolinkOptions)` accepts `enabled?: boolean` (default true); copy and validate configuration before installation. `autolinkCommands(editor)` returns instance-owned `getState(): { enabled: boolean }` and `setEnabled(boolean)`. State changes are preferences only, including in read-only. Commands after disposal throw; disposal releases all listeners and plugin API ownership. Reusing one factory result in different editors must keep state isolated. Imports and factory creation are SSR-safe.

On a real native `input` event with `inputType: insertText` and data exactly one ASCII space, after core has recorded input, inspect only a bounded suffix (at most 2050 UTF-16 units) of the current paragraph/heading/list-item/blockquote/cell flow. A collapsed caret and trailing space/NBSP are required. Recognize completed case-insensitive `http://`, `https://` and `www.` tokens, up to 2048 UTF-16 units. Add `https://` to www links; validate through the platform URL parser and existing core link validation. Do not contact URLs or fetch previews. Leading whitespace/opening parentheses/brackets/braces may delimit a URL. Keep terminal sentence punctuation and unmatched closing parentheses/brackets/braces outside the anchor; balanced URL path delimiters remain inside. Unsupported protocols, quotes/angle delimiters, ASCII control/space or DEL characters in a URL, invalid hosts and truncated token beginnings stay literal.

Never cross block, line-break, image, code, existing anchor or inline semantic-node boundaries. Do not reinterpret tokens inside anchors, pre/code, figures/captions or inline semantic wrappers. Callout/block semantic metadata and surrounding inline formatting must survive conversion. Do not convert noncollapsed selections, read-only edits, IME composition, multi-character native input, drop/history input or programmatic HTML/JSON replacement. The bounded controlled Enter and clipboard extension below adds two explicit completion routes; uncontrolled native Enter, Shift+Enter, arbitrary HTML paste and imported values remain outside those routes.

Conversion uses an atomic transaction and existing safe link commands, then restores the original post-space caret. It does not rewrite text or insert HTML strings. The preceding native text/space revision and the conversion are distinct history operations. One undo removes automatic linking and restores the literal URL including its typed space; redo restores the link and caret. Subsequent input stays outside the anchor. One conversion produces one additional user-change event. Core input and optional Markdown shortcuts remain independent.

Acceptance Chromium/Firefox/WebKit: real typing of http/https/www; sentence and balanced punctuation; rich inline content and semantic callout metadata; one-conversion undo/redo plus actual next typing; excluded contexts and URL protocols; read-only/composition/selection/paste/external boundaries; bounded long paragraphs; preference updates, two instances, cleanup and SSR. Verify built public facade imports, type declarations, zero runtime dependencies, selective imports and raw/gzip/Brotli module size. RU/EN docs must state the supported completion routes and two-operation history explicitly.

## Controlled Enter and single-URL clipboard completion

The optional plugin observes the core-owned `inputcommit` receipt specified in `events.md`. It captures bounded candidates from Enter keydown/beforeinput or an actual paste event, correlates by the original event identity and converts only after a validated changed operation. Generic `change` is not an input identity. Canceled, blocked, no-op, consumed Markdown/slash, API, history and composition paths must not produce speculative conversion. No timer, observer/diff, synthetic input or core dependency on autolink is introduced.

For controlled `insertParagraph`, require a collapsed caret after a supported URL in the current bounded flow; sentence punctuation may follow the URL exactly as for Space. Keep a live candidate Range and revalidate its text, connected ownership and excluded contexts after the receipt. Preserve the actual post-Enter collapsed DOM position in the new block. A core receipt whose `isCurrent()` is false causes no conversion: application observers may replace content, edit it, move selection, change pending formatting, destroy the editor or set read-only. The first slice excludes Shift+Enter and uncontrolled browser paragraph edits.

For an actual clipboard paste, require a collapsed source selection in a supported flow, an empty HTML representation and `text/plain` containing exactly one supported URL token of at most 2048 UTF-16 units, without whitespace or line breaks. Preserve the clipboard text verbatim, including supported terminal punctuation; link only its trimmed URL portion. After commit, verify the exact inserted suffix at the post-paste caret. Neighboring text must never be folded into the link. HTML/multiline/whitespace-delimited payloads, selected replacement and API insertion remain literal. Clipboard content is inspected locally; no URL requests or previews occur.

New completion routes wrap only the validated candidate Range inside an ordinary anchor through one validated editor transaction, retaining inline formatting. They do not temporarily move the editor selection to the URL or clear pending caret formats. Restore the exact untouched post-Enter point; for paste place the caret outside the anchor after the complete inserted token. Normalize text nodes in the affected inline container before recording the conversion snapshot, so HTML serialization cannot change the saved caret position through empty/adjacent text nodes. Subsequent actual typing must remain outside the generated anchor, including at the end of a block and after Undo/Redo.

History has two distinct operations, consistent with Space: Undo first removes automatic linking while retaining Enter/pasted literal text; Undo again removes the original input. Redo restores both operations and the post-input point. Conversion adds one additional user change. Existing Space behavior remains compatible.

Acceptance adds representative root/list/wrapped/checklist Enter, rich text and punctuation, a plain URL between neighboring text, canceled/consumed inputs, unsupported payloads/contexts/protocols, observer reentrancy/errors, retained pending formats and exact structural caret/history. Exercise all three engines without repeating the full Space matrix.

Composition guards and pending completion candidates reset when core cancels composition through an external API replacement or a transition to read-only, without requiring a later compositionend. Resuming editing must not leave autolink permanently disabled.
