# Angular adapter

Status: implementation contract. Support Angular 21 and 22. Build the library with Angular 21 partial compilation against the repository's TypeScript 5.9 toolchain; independently compile/link/install an Angular 22 consumer using its required Node/TypeScript toolchain. Do not infer version 22 compatibility solely from peer ranges or the version 21 tests.

Publish `@morfira-dev/wysiwyg-angular` and the facade subpath `@morfira-dev/wysiwyg/angular`. `MorfiraEditor` is a standalone component with selector `morfira-editor`, optional `value`, reactive `readOnly`, `locale` and `translations`, creation-time `placeholder`, `label` and `plugins`, `valueChange`, `change` and `ready` outputs, and `getEditor()`. No Angular framework code is bundled; Angular core/forms/common are peers. Angular build/compiler/linker and browser/server test dependencies are development-only.

The component implements ControlValueAccessor for reactive forms and ngModel. Do not combine a form binding and `[value]` on the same instance. `writeValue(null)` resets to an empty document; string values synchronize silently. Angular forms `disabled` combines with the readOnly input: either blocks mutations. A focus transition outside the component marks the control touched; moving within the editor does not. Disposal clears getEditor before running plugin cleanup, including when a disposer throws; Angular's normal error pipeline still observes that failure. The application owns persistence and validation beyond the editor HTML schema.

Create the editor after browser rendering and never during SSR. Native/user changes emit one valueChange/change and update the form once. Same-value acknowledgement preserves caret and history. Different external values replace content silently and clear history, including while disabled/read-only. Locale changes update UI only. Disposal releases listeners, destroys the editor and makes getEditor return undefined.

Distribute partial-compiled Angular declarations with declarations/ESM exports and sideEffects metadata. The AOT fixture compiles a standalone consumer and uses Angular's official linker for library code; it must not depend on loading the JIT compiler as a hidden fallback. SSR rendering/import must not access browser DOM or create an editor.

Acceptance: Chromium/Firefox/WebKit cover controlled value and reactive-form feedback, content/caret/history after typing, locale/readOnly updates, external replacement while disabled, touched on blur, re-enable, plugins and unmount/remount. A separate ngModel fixture verifies template-driven forms. Server import/render remains safe without window/document. Installed tarball consumers and selective core imports verify adapter/framework isolation; report unsupported Angular majors honestly.
