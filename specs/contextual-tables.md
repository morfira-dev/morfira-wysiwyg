read-only observation profile follow `table-workflows.md`. That addendum supersedes
the earlier blanket read-only ineligibility below while keeping all mutations

## Composition and table selection contract

Expose independent `/ui/contextual-table` and `/ui/contextual-table.css` through facade/plugins. `createContextualTableUI(host, editor, options?)` returns readonly element, refresh() and idempotent destroy(); export ContextualTableUIOptions/Controller/MessageKey and contextualTableUIMessages RU/EN. Options: label/onError and finite gap 0–32 CSS px, default 8. Require tables() before mounting. No new runtime dependency, core/preset import, stylesheet auto-installation, schema version, cell-selection model or node-view SDK capability.

Add a selective getTableSelection(editor, range?: Range): TableSelectionState | undefined export and extend TableCommands with registerSelectionHost(host): () => void. The observational query is separate from the command object so legacy preset/ready imports do not retain its full grid inspection. The plugin provides only a private per-editor selection-source reader for that optional helper. State owns readonly table, copied cells array (actual unique TD/TH nodes), rectangle:Readonly<CellRectangle>, rows, columns, explicit:boolean, revision:number and canMerge/canSplit booleans. Export TableSelectionState/CellRectangle and shared opaque tableSelectionChange = createPluginEvent<number>('tables:selectionchange'). State reading does not focus, move Selection, update currentTable, add UI attributes/history or mutate private selection; explicit Range projection supports lost native Selection while controls own focus. Malformed runtime Range values throw; foreign/detached/ambiguous selections yield undefined. Capabilities are observational, not command authority.

Resolve authoritative plugin-owned explicit cell selection, otherwise one ordinary native cell with both Range endpoints in that same cell/table. Never infer a logical rectangle from a cross-cell text Range or spoofed data-mw-selected attributes. For explicit logical selection, reject a conflicting native/projected range in another cell owner/table; a contained original anchor within that region is valid. Normalize spanning cells with the existing readGrid/selectionRectangle/cellsInRectangle contract. Require a complete bounded grid (100×100 maximum), no holes/overlap/foreign/semantic/nested-table content. The first UI profile rejects a table containing protected data-mw-node/foreign descendants rather than deleting another owner's content. Return undefined for unsupported structures. Merge requires at least two fully covered unique cells and complete rectangle coverage; split requires at least one spanning selected cell; read-only/composition block capabilities and actions. Other limits use rows/columns and existing logical operations.

Table plugin owns selection notifications: coalesce revision changes in one microtask, emit only after transactions have completed, skip after disposal. Notify on explicit select (including intentional same-region select), pointer selection/clear, native selection, document/API/history/read-only/composition invalidation. Revision changes represent plugin-owned logical selection intent and data/lifecycle invalidation; native-only notifications reuse the current revision. Reads never increment it. Thus a queued native event from owned focus restoration does not masquerade as a fresh explicit select. Tokens are shared identity, subscriptions are per editor and independently disposed; they are notifications, not RPC or a mutation bus. Do not emit custom events inside a transaction or let observers roll back a committed edit.

registerSelectionHost accepts a connected external HTML element in the same document, outside the editor surface and not an ancestor containing the editor element. It only preserves this plugin's logical selection on pointer interaction with owned external controls; no focus, content mutation or document event suppression. Per-editor reference-counted ownership, idempotent unregister, clear all hosts on plugin disposal. Do not register body/document/global overlay services. Native pointers outside editor/registered UI retain existing dismissal. UI registers its own mounted element and releases it on rollback/destroy.

## UI behavior

Show for a focused ordinary cell caret/same-cell text range or authoritative logical rectangle in one supported table. Save exact native Range and actual table/cell identities; getTableSelection projection does not confer mutation authority. Automatic show/layout neither focuses nor normalizes the document. Position from the first visible selected cell rectangle using shared clipped viewport geometry; use fixed above/below placement, clamped/wrapping/scrolling narrow controls. Require an empty connected external HTML host in the editor document; transformed/filter/perspective/paint/clipping host ancestors remain unsupported. Explicit CSS: core + tables.css + ui/contextual-table.css; all --mw-* scoped.

Provide eight localized native buttons: rowAbove, rowBelow, deleteRow, columnLeft, columnRight, deleteColumn, merge, split. Reuse tablesMessages labels where possible. No cell-properties forms, clipboard buttons, resize, headers/captions or extra table-delete action in this slice. Insertion is disabled at the corresponding 100-axis bound; merge/split reflect live state. Deleting all selected rows/columns can remove the table under the existing command contract, with one Undo. Operations through spans preserve unaffected actual cell content and adjust spans through existing commands, never UI DOM edits.

Before executing, restore saved Range and revalidate API revision, actual table/cells, selection rectangle, read-only/composition/disposal and current capabilities after focus callbacks. Reselect the same logical rectangle with existing select only when needed; do not silently retarget a draft/action after API replacement, Undo/recreated nodes or a different table/cell selection. Unsupported or failed operations leave document/history unchanged. Each enabled structural action is its normal single atomic command/Undo; dismiss after successful action, then a genuine selection or explicit Alt+F10 can reopen. Preserve native cell bookmark/history rather than mapping through text offsets. Hidden/detached controls and queued callbacks cannot mutate replacement content.

Read-only/composition/API replacement dismiss and invalidate. Escape dismisses pending/visible opening and returns a valid saved range once, without calling a disposed editor. Outside pointer/focus departure dismiss without stealing focus. Same-session queued refresh/selection/RAF cannot reopen dismissal; a genuine selection action, intentional table select revision or Alt+F10 may reopen. Own button pointerdown preserves selection and focus; registered host prevents legacy outside-clear races without stopPropagation. Alt+F10 from this editable table surface focuses first enabled control; other editors/ranges and readonly retain shortcuts. Native Tab navigation continues to work; toolbar Tab controls need no new global keyboard service.

Coexistence: selected link carets and exact IMG ranges use their dedicated UI; noncollapsed same-cell text ranges may use text formatting rather than two competing bubbles. First table UI therefore opens automatically for a collapsed caret or explicit multi-cell plugin region (and explicit Alt+F10 for an eligible noncollapsed same-cell range). Do not show at a caret inside A, exact IMG node selection or caption/semantic nodes. No global overlay coordinator. Keep geometry-only hidden sessions observable for scrollback, but cancel owned RAF/scroll/resize/VisualViewport/ResizeObserver work on dismissal/ineligibility/destruction. No polling or document-wide traversal; grid/state work occurs on selection/data changes or activation, not passive field keys or geometry-only frames.

### Selective query boundary decision

The first built API attached the complete query to every TableCommands instance; it raised the existing maximal standard profile from 64618 to about 65400 gzip JS bytes, exceeding its then-current 65000 guard by about 400 bytes. Move observation to a separately tree-shakable getTableSelection export rather than retaining full inspection in all command objects. Preserve private plugin selection ownership, the event/host contracts and the same snapshot type. This is an unpublished additive API design correction, not a runtime-flag tree-shaking claim or a budget increase. Final numbers require a rebuilt public profile.
