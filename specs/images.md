# Images: optional commands and application-owned upload

Status: implemented locally; full check passes 306 browser tests across Chromium/Firefox/WebKit (60 image scenarios), docs build and 17 site tests pass. Original strict TypeScript, zero runtime dependencies. Public entry `@morfira-dev/wysiwyg/plugins/images`; `images(options)` plugin and `imageCommands(editor)` API. Schema v1 adds semantic figure/figcaption tags (additive; older readers discard wrappers/caption semantics). Core never imports images plugin. A root document ending in figure receives a trailing empty paragraph, as for tables. Core insertHTML treats figure as a block.

## Commands and persisted data

`ImageValue { src: string; alt?: string; width?: number; height?: number; caption?: string }`; `insert(value)`, `select(image)`, `getSelected()`, `update(partialValue)`, `remove()`. HTML/JSON image dimensions are authoritative and mirror into validated inline pixel styles to resist host stylesheet resets; updating/removing dimensions keeps both representations synchronized. Width/height are positive integer HTML dimensions 1–1000; undefined leaves metadata, null removes dimensions in update. Caption is literal text up to 5000 characters; empty removes it; alt up to 20000. URLs use the shared image schema (http/https or relative, no data/blob/script). Invalid values reject atomically before mutation.

Insert creates a block figure containing img and optional figcaption. Replace a selection only within the same paragraph/heading or container; reject selections across blocks/cells/list items atomically. A selected single-image figure is replaced as a unit (including its old caption), never nested. Reject insertion in complex imported figures. Split a paragraph around the figure and place caret in the following paragraph, preserving surrounding marks. Figures remain inside list items/table cells; merged-cell geometry remains unchanged. Caption editing uses native input/history. Updating a caption on a legacy inline image promotes it to a figure. Updates without caption keep legacy inline images in place; existing unrelated validated image attributes survive. Caption removal preserves the figure/image. Remove deletes the owned figure or just the inline img; unrelated surrounding/cell/list content stays intact. Commands form one undo transaction each, respect read-only and restore selection on history navigation.

`select(image)` requires this editor's img and selects its DOM node. Clicking an image selects it. The demo captures selection/metadata synchronously on image click before a rapid form-focus change; form focus retains that bookmark; getSelected/update/remove derive the actual current image selection, including a caret in its caption. A selection spanning multiple images is not a single-image selection. No resize handles, drag/drop, crop or automatic aspect-ratio locking in this milestone.

## Upload lifecycle

Options `upload(file, { signal }): Promise<ImageValue>`, optional maxFileSize (default 10 MiB). Validate file.size >0 within limit and MIME image/png, image/jpeg, image/gif, image/webp, image/avif before callback. SVG/executable file formats rejected. Application owns transport, credentials, storage and server validation; the client MIME gate is not server-side validation.

`upload(file): Promise<boolean>` captures the current valid selection and awaits the callback, then validates the result and inserts one image transaction at that bookmark. Selection-only movement does not relocate the insertion. Return true on insertion, false when cancelled; errors reject for caller UI. `cancelUpload()` aborts the signal; `isUploading()` reports state. Latest request wins. Any document change/external replacement, read-only transition or disposal cancels the request; disposed APIs throw except idempotent cancelUpload. Late results/rejections after cancellation cannot mutate or cause unhandled rejections. No temporary nodes or object URLs are persisted. Per-instance state only; dispose all subscriptions/listeners.

## Local bilingual demo

Both homepages/playgrounds expose image sample, src/alt/width/height/caption fields, insert/update/remove, file upload and cancellation, loading/error status. The local demonstration callback returns /logo.svg for an accepted raster file and explicitly says it does not upload/store the selected file; it is a callback/lifecycle example, not a file preview or production upload. User files never leave the tab. Demo callback uses AbortSignal with timer cleanup. Show existing image metadata when selection changes, keep drafts during form focus. CSS variables control image/caption spacing, color and font size; scope styles to .mw-content.
