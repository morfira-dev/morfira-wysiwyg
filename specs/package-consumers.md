# Isolated package consumer verification

Status: accepted tooling contract. This checks installable package artifacts, not source aliases or npm publication. It adds no runtime/editor dependency or new development dependency.

The runner requires an existing successful library build. It packs the six libraries into real tarballs and creates a temporary consumer outside the pnpm workspace. Its dependency and pnpm workspace override entries point to those tarballs. Framework/compiler/bundler versions (including tsx, the runner’s existing tool and an explicitly installed Vite optional peer) and their transitive dependency edges are pinned to the actual installed repository graph. Version-qualified parent>child pnpm overrides preserve multiple compatible package versions instead of globally forcing one version. The runner bounds candidate directories and resolved paths to each graph’s own node_modules before accepting a package; loader/global lookup fallbacks are ignored. Peer-only edges require a binding in the package’s own node_modules or immediate pnpm peer context, so unrelated inherited/hoisted optional peers are recorded as absent instead of being imported into the graph. The runner follows each physical package context, fails on missing required dependencies or ambiguous parent/version edges, and verifies that the isolated installed graph matches before compiling. Uninstalled optional peers are recorded; uninstalled platform-specific optional dependencies must already have exact versions, otherwise the runner fails rather than guessing a resolution. Installation uses pnpm 11.0.7 with `--offline`; a missing cached dependency fails explicitly instead of fetching from npm or silently using workspace links.

The consumer owns normal Vue SFC, React StrictMode and Svelte 5 examples. It imports supported facade/adapter/plugin/CSS exports without TypeScript paths or Vite aliases, type-checks TS/TSX, Vue and Svelte, then creates a production build. Installed package and entry realpaths must remain within the isolated consumer node_modules; artifact versions and archive hashes are recorded. The check must not publish, modify manifests or install packages in the repository.

The React example includes a StrictMode wrapper; a production build does not exercise development-only effect replay (covered separately by the project adapter suite). Browser acceptance uses the built consumer in Chromium, Firefox and WebKit: real typing survives controlled feedback; a structural slash action produces one final change and supports history/following input; external values do not emit user changes; reactive read-only blocks input but accepts an external value; unmount removes editor and optional menus and disposes its API. Browser failures and page errors fail the run. These are recorded smoke scenarios, not broad mobile/IME/accessibility certification.

The runner binds an ephemeral localhost port, closes pages/browsers/server and removes its owned temporary directory in finally. A JSON report under ignored artifacts records package/tool versions, archive hashes, resolved artifact locations, the root lockfile SHA256, exact toolchain edge overrides/absent optional packages and actual browser results. No unstable timing assertion or registry availability is part of acceptance.
