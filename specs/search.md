# Find and replace — optional module

Status: implemented locally; full check passes 405 browser tests across Chromium/Firefox/WebKit and 23 bilingual site tests pass. Original strict TypeScript, zero new dependencies, MIT. Public entry `@morfira-dev/wysiwyg/plugins/search`, `search()` plugin, `searchCommands(editor)` API. Core must not import it. Independent entry size including shared chunks: 150000 gzip JS byte guardrail (user-directed optional-module envelope). Schema v1 unchanged.

## Literal search and boundaries

`SearchOptions { caseSensitive?: boolean; wholeWord?: boolean }`; `SearchMatch { index: number; length: number; text: string }`; `SearchState { query: string; options: { caseSensitive: boolean; wholeWord: boolean }; matches: SearchMatch[]; current: number; error?: 'match-limit' }`. current is a zero-based match index, -1 if no matches. Offsets are UTF-16 global textContent offsets, matching core selection API (not innerText synthetic line separators).

`search()` plugin; commands `setQuery(query, options?)`, `getState()`, `select(index)`, `next()`, `previous()`, `replaceCurrent(replacement): boolean`, `replaceAll(replacement): number`, `clear()`, `subscribe(listener): () => void`. setQuery, clear, select return void; next/previous return SearchMatch | undefined. subscribe returns disposer; does not invoke immediately. getState returns independent deep snapshots. setQuery validates atomically then sets current=0 if matches exist, otherwise -1, without changing DOM selection/focus/history. Options default false each setQuery. Query is literal text, regex syntax is escaped. Empty query clears; maximum 1000 UTF-16 units. Replacement is literal text (including <markup>, $, Unicode), maximum 20000 UTF-16 units; reject CR/LF to avoid creating layout-only line breaks instead of document blocks. Invalid arguments throw before mutation. Queries with CR/LF reject as well. Search uses JS Unicode regex case folding (u+i), not locale-specific rules or normalization.

Matches are non-overlapping. Search may cross adjacent inline text nodes/marks/links, but never paragraphs/headings, list item boundaries/nested lists, cells, captions, pre/blockquote block boundaries, or br/img/hr. Captions are searchable text; image alt/title/attributes and other editor instances are excluded. Whole words use Unicode Letter/Number/Mark/Connector_Punctuation boundaries; emoji/punctuation are separators. A query may include spaces/punctuation; only its outside boundaries are checked. More than 10000 matches rejects setQuery atomically. If a passive native/API document update exceeds the limit, preserve query/options, publish error='match-limit' with empty matches/current=-1 and do not throw from the editor subscription or roll back the edit; recover automatically under the limit. Replacement while overflow is active rejects clearly. Otherwise never truncate; never silently replace a truncated result set. Avoid quadratic per-match scans; collect text runs/leaves once and map matches using offsets/binary search.

Registered semantic wrappers (`data-mw-node`) and foreign namespaces are opaque
search barriers: do not index their descendants or match across them. Advance
global UTF-16 offsets by their visible text so following ordinary matches still
select correctly. This preserves persistent mention identities under automatic
replacement; explicit native editing retains that feature's separate contract.
The rule covers any owning semantic node, without importing the mentions module.
Actual new validation results belong to verification-backlog.md.

## Navigation and replacement

The optional [search highlights](search-highlights.md) module adds non-persisted
all-result/current paint through native CSS highlights. The independent
getSearchRanges(editor) observation returns fresh current Range clones plus the
active index, after pending index updates; it never changes selection/history.
Semantic ownership attribute changes invalidate indexing alongside text/children.
Ranges are ephemeral, not validated mutation targets or mapped SDK positions.

select validates a match index, focuses the editor, selects the exact DOM text range and scrolls that range into view. next/previous wrap around; no results are no-ops. Native Selection marks the active result; no persistent marks/wrappers or claim of highlighting all matches. Find/navigation do not create history. Searching works in read-only; replace returns false/0 in read-only or during IME composition.

Commands replace their indexed current match, independent of form focus/another DOM selection. Replace only text, retaining all block/table/list/figure structure, unaffected marks/links/styles, image nodes and merged-cell spans. Replacement inherits inline formatting/link at the match start, even across multiple text leaves; never inserts executable HTML. Removing matched text may leave empty inline wrappers, which have no visible text. Replacing a whole multi-node match must not delete surrounding tags or unrelated content. A single replace is one transaction; replaceAll snapshots matches and replaces in reverse document order in ONE transaction. It must not replace freshly inserted matching text in the same invocation. No matches, read-only, identical replacement are no-op history operations. After replacement, caret is at the inserted text end (first replacement for replaceAll). After replaceCurrent choose the first remaining match at/after the inserted text end, wrapping if necessary. Query results update after input, formatting, undo/redo and external document replacement without moving selection. Preserve the nearest active match by text position where possible. External replacement emits no user change; core history reset semantics remain intact.

Subscriptions notify for query/current/result changes and disposal is per instance. Reentrant notification must not corrupt pending operations; iterate listener snapshots and compute a fresh result snapshot per listener. An instance MutationObserver tracks childList/characterData and is drained before navigation/replacement, so identical-HTML no-op commands that recreate text nodes cannot leave stale ranges. Bound projected replacement text at the shared 5000000-unit document limit before allocating planned strings. Dispose that observer, plugin subscriptions, composition listeners and any external resources; disposal makes commands throw, returned unsubscribe stays idempotent. Creating/reusing a plugin across multiple editors must not share state. SSR import/factory evaluation must not touch DOM.
