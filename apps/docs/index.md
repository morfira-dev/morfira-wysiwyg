The full homepage and playground explicitly install the optional [table size picker](/table-picker) and [image clipboard/drop input](/image-input). Use the Table toolbar button for the 8 × 8 picker, or paste/drop one raster file into ordinary text. The local upload callback returns the logo; it does not send or store the file.


The Tables section also installs the ready [table and cell properties form](/table-properties): select a cell or spanning rectangle, then change width, placement, colors and vertical alignment. Apply edits only dirty fields as one Undo operation.

A complete integration path: an [editor field with saving](/editor-field) and [saved-content display](/content-view) outside the editor. Open “Write, save and publish” below to try the complete local workflow.

Try [everyday table operations](/table-workflows), [application-owned extensions](/application-extensions), and [integration scenarios with explicit feedback preparation](/integration-feedback).
