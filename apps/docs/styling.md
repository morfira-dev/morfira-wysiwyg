# Цвета и ссылки

Готовая необязательная форма `createLinkForm` доступна через `@morfira-dev/wysiwyg/ui/links`. Она использует те же команды, сохраняет выделение при работе с полями и поддерживает локализацию. [Подключение формы без фреймворка](/ui#ссылки-без-фреймворка).

`format('color', value)` задаёт цвет текста, `format('background', value)` — цвет выделения. Значение — имя CSS-цвета, hex, rgb/hsl или `false` для снятия соответствующего inline-свойства. Произвольный CSS и `var()` не принимаются. Цвет блока при этом сохраняется.

```ts
editor.format('color', '#6658e8');
editor.format('background', 'yellow');
editor.format('color', false);
```

Выделение может пересекать абзацы, списки и ячейки: структура и остальное форматирование сохраняются. Без выделения цвет применяется к последующему вводу. Перемещение курсора или внешняя замена документа сбрасывают ожидающее форматирование. Undo/redo восстанавливает документ и курсор. `getFormats()` возвращает `color`, `background` и массив `mixed`; цвета могут быть нормализованы браузером в rgb.

```ts
import type { LinkFormat } from '@morfira-dev/wysiwyg';
const link: LinkFormat = {
  href: 'https://example.com', title: 'Пример', target: '_blank',
};
editor.format('link', link);
editor.format('link', '/guide'); // меняет только URL
editor.format('link', false);
```

При выделении команда меняет или снимает ссылку только с выделенного фрагмента, сохраняя соседние ссылки и текстовые стили. Внутри ссылки без выделения меняется вся ссылка. Пропущенные title/target сохраняются, `title: ''` снимает заголовок. `getFormats()` сообщает `link`, `linkTitle`, `linkTarget` и смешанные значения.

В пустой позиции вне ссылки можно создать текстовую ссылку:

```ts
editor.format('link', { href: '/guide', text: 'Документация' });
```

`text` — буквальный текст, допустим только при создании ссылки в позиции курсора вне существующей ссылки. Курсор остаётся после неё. Без text и выделения команда вне ссылки ничего не делает.

Допустимы http/https/mailto/tel и относительные URL. Небезопасные URL и некорректные параметры API отклоняются с исключением до изменения документа. Target принимает только `_self`/`_blank`; `_blank` автоматически получает `rel="noopener noreferrer"` при HTML/JSON импорте и редактировании. Команды учитывают read-only и историю. Автоматической загрузки превью URL нет.

На [главной](/#editor) и [стенде](/playground) есть пример «Цвета и ссылки», формы цвета/выделения, заголовка и открытия в новой вкладке. Фокус в полях сохраняет выделение редактора. Кнопки сброса относятся к inline-цветам документа; CSS-переменные темы меняются отдельно.

Изменение поведения API: раньше некорректный URL команды link мог игнорироваться. Теперь обрабатывайте исключение (например, через try/catch формы). Импорт HTML/JSON по-прежнему очищает неподдерживаемые атрибуты.

Дополнительно можно явно подключить [действия ссылки у курсора](/contextual-links): просмотр безопасного адреса, Open/Edit/Remove и существующая форма. Это отдельный `/ui/contextual-link`, без изменения пресета или ready toolbar; image/table contexts остаются вне первого среза.

На главной и в playground цвет текста/фона применяется при подтверждении выбора
в палитре, без дополнительного нажатия «Применить». После перехода фокуса в
палитру восстанавливается выделенный диапазон редактора. Кнопки применения и
сброса также остаются доступны.
