# Плагины и таблицы

## Подключение таблиц

```ts
import { createEditor } from '@morfira-dev/wysiwyg';
import { tables, tableCommands } from '@morfira-dev/wysiwyg/plugins/tables';
import '@morfira-dev/wysiwyg/style.css';
import '@morfira-dev/wysiwyg/plugins/tables.css';

const editor = createEditor(host, { plugins: [tables()] });
const table = tableCommands(editor);
table.insert(3, 4);
table.select({ row: 0, column: 0 }, { row: 0, column: 1 });
table.merge();
```

Размеры — целые числа от 1 до 100. Вставка вложенных таблиц отклоняется. Собственная логическая сетка учитывает объединения; команды входят в общую историю редактора. Разреженные таблицы нормализуются при структурном редактировании; пересечения и превышение лимитов отклоняются.

## Команды

`insert`, `select`, `rowAbove`, `rowBelow`, `columnLeft`, `columnRight`, `deleteRow`, `deleteColumn`, `merge`, `split`, `remove`, `background(color)`, `border(color)`, `columnWidth(column, pixels)`.

Строки/столбцы и цвета применяются к выделению или текущей ячейке. `select` использует логические адреса с нуля; область расширяется через существующие объединения. Merge сохраняет содержимое в порядке документа; split оставляет содержимое в исходной ячейке. Ширина столбца — 40–4000 px. Режим чтения блокирует изменения.

Перетаскивайте по ячейкам или используйте Shift-click для выделения. Правая кнопка открывает русское контекстное меню. Tab/Shift+Tab перемещает по ячейкам; Tab в последней добавляет строку. На правой границе ячейки есть изменение ширины; завершённое перетаскивание — одна операция истории. Полное touch-управление и изменение размера только с клавиатуры ещё требуют работы.

## Свой плагин

```ts
import type { EditorPlugin } from '@morfira-dev/wysiwyg';

const counter = (): EditorPlugin => ({
  name: 'counter',
  setup: (editor) => {
    const stop = editor.subscribe(({ text }) => console.log(text.length));
    return stop;
  },
});
```

Setup возвращает очистку ресурсов. `providePlugin` и `getPlugin<T>` открывают API конкретного экземпляра. `transact` объединяет доверенные DOM-операции в атомарное изменение с историей. Плагины подключаются при создании; каждая подписка и UI-ресурс удаляются при уничтожении. Глобального реестра форматов нет, ядро не импортирует общий индекс плагинов.

## Буфер табличного диапазона

`copy()` возвращает `{ html, text }` без доступа к системному буферу. `cut()` возвращает те же данные и очищает выделенное содержимое одной транзакцией. `paste({ html?, text? })` принимает одну проверенную таблицу или TSV. HTML сохраняет объединения/стили; TSV поддерживает кавычки, табы/переносы внутри значения и удвоенные кавычки. Сетка расширяется вправо/вниз в пределах 100 × 100. Частично пересекаемое объединение отклоняется атомарно. Одиночное значение заполняет явно выделенные ячейки; размер большего источника должен совпадать с выделением.

Внутри таблицы системный буфер распознаёт HTML-таблицу или текст с табами. При явном выделении ячеек также принимается одиночный текст или rich text. Без выделенного диапазона обычное копирование текста и rich-text вставка сохраняют поведение браузера/ядра. Текст только с переносами автоматически не считается таблицей; для одного столбца есть явный paste API.

```ts
const commands = tableCommands(editor);
const payload = commands.copy();
commands.paste({ text: 'Название\tЗначение\nЯзык\tTypeScript' });
// tables({ onClipboardError: (error) => report(error.message) })
```

Некорректные кавычки, вложенные/несколько таблиц, превышение лимитов и несовпадение размера не меняют документ. Ошибка браузерной вставки выводится через доступный status; `onClipboardError` позволяет сообщить её приложению. API выбрасывает ошибки валидации. Тестовые clipboard-примеры проверяют эти форматы, но не означают совместимости с любой вставкой Word/Excel.

[Поиск и замена](/ru/search) подключается отдельно через `/plugins/search`; ядро не требует этот модуль.

[Статистика текста](/ru/statistics) — отдельный `/plugins/statistics` для графем и слов документа/выделения.

[Markdown shortcuts](/ru/markdown) — необязательный `/plugins/markdown` для преобразований при вводе; загрузка и вставка текста остаются буквальными.

[Упоминания и slash-шаблоны](/ru/suggestions): `/plugins/mentions`, `/plugins/slash`, необязательные `/plugins/suggestions` и `/plugins/suggestions.css`. Первый этап вставляет обычный текст и не сохраняет ID.

## Чек-листы

Отдельный [плагин чек-листов](/ru/checklists) и его CSS подключаются явными импортами. Он даёт команды одного пункта, клик по маркеру и Ctrl/Cmd+Enter; встроенное взаимодействие отключается через `interactive: false`. Обычный core-only редактор не загружает плагин.


Необязательная команда [разделителя](/ru/horizontal-rule) доступна через `/plugins/horizontal-rule`: один корневой абзац/заголовок, редактируемый остаток и один Undo. Standard/extended подключают её и кнопку готовой панели по умолчанию; `horizontalRule: false` отключает экземпляр.

Необязательный [плагин шрифтов](/ru/fonts) через `/plugins/fonts` задаёт настроенное семейство и px-размер, независимый сброс и фактическое/mixed CSS-состояние. Он подключается явно, не входит в пресеты и не загружает файлы шрифтов.

Явный плагин [свойств списка](/ru/list-properties) задаёт start, reversed и ограниченный list-style-type контейнера; без отдельного CSS, счётчиков или изменений пресетов.

Необязательное [направление текста LTR/RTL](/ru/text-direction) через `/plugins/text-direction` меняет явный dir ближайшего обычного блока или соседних блоков с общим родителем/ячейкой. Reset наследует окружение, а не включает LTR; пресеты и ready toolbar не подключают плагин автоматически.

Для форматирования непустого выделения доступен отдельный [контекстный UI](/ru/contextual-toolbar), а не новый behavior-плагин: `/ui/contextual` и явный `/ui/contextual.css`. Он не устанавливается пресетами и использует существующие команды/историю.

## Контекстные действия таблиц

Явно подключаемая [контекстная панель таблиц](/ru/contextual-tables) добавляет вставку/удаление строк и столбцов, merge/split поверх существующей логической сетки, восстановление native Range и один шаг Undo на команду. Подключите `/ui/contextual-table` и его CSS вместе с `tables()` и CSS таблиц; пресеты не меняются. `getTableSelection(editor, range?)` возвращает наблюдаемый `TableSelectionState`, `registerSelectionHost(host)` задаёт владение внешними контролами, а `tableSelectionChange` — типизированное уведомление экземпляра, не RPC. Гайд описывает spans, недоступные действия, клавиатуру/lifecycle.


Необязательный [выбор размера таблицы](/ru/table-picker) подключается явным импортом фабрики и CSS; [вставка изображения из буфера/drop](/ru/image-input) использует callback загрузки приложения. Пресеты автоматически их не включают.


[Свойства таблиц и ячеек](/ru/table-properties) подключаются отдельными `/plugins/table-properties` и `/ui/table-properties`: ширина/расположение таблицы, фон/цвет границ/вертикальное выравнивание выбранных ячеек. Форма применяет только изменённые поля одним Undo, использует существующий `/ui/forms.css` и не входит в пресеты.
