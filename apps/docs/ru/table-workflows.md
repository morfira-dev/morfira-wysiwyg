# Таблицы в ежедневной работе

Создайте и заполните таблицу существующим [плагином таблиц](/ru/plugins), затем
используйте отдельные [контекстные действия](/ru/contextual-tables) для структуры
и выделения диапазонов. Все изменения используют логическую сетку объединённых
ячеек и участвуют в Undo.

## Выделение строк, столбцов и таблицы

```ts
import { tableCommands, getTableSelection } from '@morfira-dev/wysiwyg/plugins/tables';

const table = tableCommands(editor);
table.selectRow();
// Другие варианты: table.selectColumn(); или table.selectTable();
const selection = getTableSelection(editor);
```

Поставьте курсор в ячейку либо сначала выделите прямоугольник ячеек. `selectRow()`
выделяет на полную ширину все строки, затронутые диапазоном; `selectColumn()` —
его столбцы на полную высоту. `selectTable()` выделяет всю обычную таблицу. Команды
сохраняют настоящие ячейки, нативный текстовый диапазон, экспортируемый документ
и историю Undo. Они доступны в read-only для последующего копирования. Composition
оставляет выделение прежним. Некорректная, защищённая, вложенная или разреженная
сетка и устаревший контекст каретки отклоняются до замены старого выделения.

**Объединённые ячейки выделяются целиком.** Прямоугольник расширяется, пока его
границу пересекают rowspan/colspan. Поэтому выделение одной строки иногда включает
дополнительные строки, а столбца — соседние столбцы. Живая сводка показывает
логические строки × столбцы и число настоящих выделенных ячеек.

В редактируемой таблице нажмите **Alt+F10**, перейдите Tab к **«Выделить строки»**,
**«Выделить столбцы»** или **«Выделить таблицу»** и нажмите Enter. Нативное текстовое
выделение Shift+Arrow не заменяется. Переход в read-only закрывает прежний сеанс
панели; новое взаимодействие с таблицей разрешает выделение, а изменение структуры,
merge/split остаются отключёнными. Клавиатурный фокус в read-only также зависит
от фокусируемого контейнера приложения и поведения браузера.

## Заполнение, копирование, оформление и отмена

1. Загрузите простую таблицу и нажмите **«Выделить таблицу»**.
2. Выберите **«Вставить учебный TSV»**. По существующим правилам буфера заполнится
   диапазон 2 × 2; таблица не заменяется обычным текстом.
3. Снова выделите таблицу и выберите **«Скопировать HTML и TSV»**. Просмотр локальный:
   он не обращается к системному буферу и не отправляет содержимое.
4. Нажмите **«Цвет выбранных ячеек»**, затем Undo/Redo. Каждое изменение имеет
   обычную одношаговую историю. Структура изменяется контекстными действиями.
5. Загрузите таблицу с объединениями и выделите строку/столбец для просмотра
   расширения по spans. Загрузка заменяет документ и задаёт новую базу истории.

Учебный TSV написан для этой демонстрации. У реальной [офисной вставки](/ru/office-paste)
есть отдельный корпус исходников и контракт форматов. Эти примеры не заявляют
полную совместимость с Excel.

## Отдельное подключение и очистка

Команды принадлежат `tables()`. Контекстная панель остаётся отдельной фабрикой
с отдельным CSS:

```ts
import { createContextualTableUI } from '@morfira-dev/wysiwyg/ui/contextual-table';
import '@morfira-dev/wysiwyg/style.css';
import '@morfira-dev/wysiwyg/plugins/tables.css';
import '@morfira-dev/wysiwyg/ui/contextual-table.css';

const controls = createContextualTableUI(externalHost, editor);
// При удалении экрана: controls.destroy(); editor.destroy();
```

Панель принадлежит одному редактору и пустому внешнему контейнеру. Наблюдение
выделения не разрешает изменение: действия повторно проверяют цель после focus
callbacks. Метаданные таблицы и оформление ячеек настраиваются отдельной
[формой свойств](/ru/table-properties).
