# Переиспользуемые UI-формы

Формы ссылок, изображений и поиска — готовый необязательный интерфейс поверх публичных команд редактора. Они не зависят от Vue/React/Angular/Svelte или CSS сайта документации. Главная страница и playground используют эти же фабрики.

Каждый JS-вход подключается отдельно. Стили импортируются явно; импорт UI не регистрирует глобальные элементы и безопасен на сервере. Создание формы требует браузерного DOM.

| Фабрика | Публичный вход | Требуемый плагин |
| --- | --- | --- |
| `createLinkForm` | `@morfira-dev/wysiwyg/ui/links` | Не нужен: используются команды ядра |
| `createImageForm` | `@morfira-dev/wysiwyg/ui/images` | `images()` |
| `createSearchForm` | `@morfira-dev/wysiwyg/ui/search` | `search()` |

Общий CSS: `@morfira-dev/wysiwyg/ui/forms.css`. Отсутствие необходимого плагина обнаруживается до монтирования формы. Ни один UI-модуль не требуется для работы ядра.

Контейнеры форм изображений и поиска должны находиться вне `editor.surface`: сама поверхность и её потомки отклоняются до монтирования и установки обработчиков. Используйте отдельный соседний контейнер. См. [границы безопасности](/ru/security).

## Ссылки без фреймворка

Добавьте два пустых контейнера:

```html
<div id="link-editor"></div>
<div id="link-controls"></div>
```

```ts
import { createEditor } from '@morfira-dev/wysiwyg';
import { createLinkForm } from '@morfira-dev/wysiwyg/ui/links';
import '@morfira-dev/wysiwyg/style.css';
import '@morfira-dev/wysiwyg/ui/forms.css';

const editor = createEditor(document.querySelector<HTMLElement>('#link-editor')!, {
  locale: 'ru', value: '<p>Выделите текст для ссылки.</p>',
});
const form = createLinkForm(document.querySelector<HTMLElement>('#link-controls')!, editor, {
  initialValues: { href: 'https://example.com', newTab: true },
  onError: (error) => console.error('Link command failed', error),
});

editor.setSelection(0, 8);
form.refresh();

const dispose = () => {
  form.destroy();
  editor.destroy();
};
// Вызовите dispose() при удалении экрана.
```

Форма создаёт/обновляет ссылку и снимает её, сохраняет выделение при переходе в поля. Заголовок, новая вкладка и URL используют существующую валидацию команд. Поле `text` нужно для новой ссылки без выделения; оно не заменяет текст существующей ссылки. Для `_blank` ядро сохраняет безопасный `rel`.

Для контекстного редактирования существующей ссылки доступна явная настройка `scope: 'anchor'`. Форма принимает только курсор/диапазон внутри одного обычного anchor, меняет его метаданные или снимает ссылку целиком, сохраняя исходное выделение. В этом режиме нет создания ссылки и изменения текста. По умолчанию используется `scope: 'selection'`: обычное форматирование выбранного диапазона сохраняет прежнее поведение.

## Изображения и загрузка приложения

Контейнеры: `<div id="image-editor"></div>` и `<div id="image-controls"></div>`.

```ts
import { createEditor } from '@morfira-dev/wysiwyg';
import { images } from '@morfira-dev/wysiwyg/plugins/images';
import type { ImageValue } from '@morfira-dev/wysiwyg/plugins/images';
import { createImageForm } from '@morfira-dev/wysiwyg/ui/images';
import '@morfira-dev/wysiwyg/style.css';
import '@morfira-dev/wysiwyg/ui/forms.css';

const editor = createEditor(document.querySelector<HTMLElement>('#image-editor')!, {
  locale: 'ru', value: '<p>Место для изображения.</p>',
  plugins: [images({
    maxFileSize: 5 * 1024 * 1024,
    upload: async (file, { signal }) => {
      const body = new FormData();
      body.append('file', file);
      const response = await fetch('/api/uploads', { method: 'POST', body, signal });
      if (!response.ok) throw new Error('Upload endpoint rejected the file.');
      return await response.json() as ImageValue;
    },
  })],
});
const form = createImageForm(document.querySelector<HTMLElement>('#image-controls')!, editor, {
  initialValues: { src: '/assets/photo.png', alt: 'Описание', width: '320' },
});
editor.setSelection(0);

const dispose = () => {
  form.destroy();
  editor.destroy();
};
```

`/api/uploads` — пример API вашего приложения, не поставляемый сервер. Он должен вернуть `ImageValue` с URL и необязательными alt/размерами/подписью. Плагин проверяет возвращённые метаданные. Выбор файла не означает автоматическую загрузку в какое-либо внешнее хранилище Morfira: транспорт полностью принадлежит приложению.

Форма поддерживает URL, alt, подпись, размеры, вставку, обновление и удаление выбранного изображения, выбор файла и отмену. При выключенном сохранении пропорций пустые поля размеров снимают соответствующие ограничения при обновлении. Удаление формы отменяет только её собственный upload; поздний результат не вставляется. Resize мышью, crop и drag/drop не добавляются этим модулем.

Для своего интерфейса можно передать отдельный сигнал в `imageCommands(editor).upload(file, { signal })`; тип опций — `ImageUploadOptions`. Это отменяет именно данный запрос. `cancelUpload()` остаётся командой отмены текущей загрузки редактора. [Подробнее об изображениях](/ru/images).

### Прогресс загрузки и повтор

В режиме `all` форма показывает нативный индикатор **«Прогресс загрузки изображения»**: процент при наличии общего числа байтов, иначе неопределённый прогресс. Данные поступают из callback приложения через `ImageUploadContext.reportProgress({ loaded, total? })`; готовый транспорт не добавляется. Необязательный `ImageUploadOptions.onProgress` доступен собственному UI. 100% передачи ещё не означает, что результат прошёл проверку и вставлен.

Ошибка отображается общим локализованным текстом, без вывода HTML ответа и текста исключения. **«Повторить загрузку»** запускает новую попытку с прежним File в исходной позиции. Остальные черновики формы не отправляются. Перемещение курсора не переносит повтор; любое изменение документа/Undo/API-замена, read-only, IME, другой файл, отмена или уничтожение формы сбрасывают повтор и освобождают файл. Каждая попытка проходит валидацию, успех — одна вставка и один Undo. Автоматических повторов нет; загрузки других владельцев не затрагиваются. В режиме `edit` индикатор и повтор отсутствуют; тип `ImageFormValues` не меняется.

В главной демке и playground переключатель **«Ошибка следующей загрузки»** демонстрирует одну ошибку, затем успешный повтор. Процент имитируется таймером, файл не читается и не отправляется. [API прогресса и обязанности сервера](/ru/images#прогресс-ошибки-и-повторная-попытка).

### Сохранение пропорций

Для уже выбранного изображения доступен переключатель **«Сохранять пропорции»**. Включите его и измените ширину или высоту: другая сторона пересчитается по фиксированной пропорции инспектируемого изображения. До нажатия «Обновить изображение» меняются только черновики. В режиме `edit` Enter применяет обновление; в режиме `all` прежний Enter для вставки сохраняется.

```ts
const form = createImageForm(formHost, editor, {
  mode: 'edit',
  keepAspectRatio: true,
});
```

`ImageFormOptions.keepAspectRatio` — необязательный boolean, по умолчанию `false`. Значение проверяется и копируется при создании; состояние переключателя принадлежит форме и не сохраняется в документ. Сначала берётся сохранённая пара размеров, иначе — уже загруженные естественные размеры. При отсутствии пропорции переключатель недоступен; дополнительной загрузки ради вычисления нет. Вычисленная сторона округляется до пикселя и должна остаться в диапазоне 1–1000.

Неверный, пустой или слишком большой размер при включённой блокировке не применяется: черновики остаются для исправления. Выключите переключатель для независимых сторон или снятия размеров. `setValues` сохраняет переданные строковые черновики без автоматического пересчёта; обновление проверяет, что итоговая пара соответствует зафиксированным пропорциям. Смена src, изображения или внешняя API-замена не могут применить старую пропорцию к новой цели. Изменение размеров и остальных метаданных выполняется одним Undo; неизменённая rich-подпись сохраняет свои узлы. Локализация меняет подпись переключателя через `ui.images.keepAspectRatio`, не сбрасывая черновик. См. [команду resize](/ru/images#размер-с-сохранением-пропорции).

### Выравнивание изображения

Группа **«Выравнивание изображения»** доступна в обоих режимах формы и в контекстных свойствах. Кнопки **«Изображение слева»**, **«Изображение по центру»**, **«Изображение справа»** и **«Сбросить выравнивание изображения»** сразу вызывают команду для выбранной картинки. Остальные поля остаются черновиками и не отправляются. `aria-pressed` отражает явное размещение; сброс активен, когда оно не распознано. Формат `ImageFormValues`, `getValues` и `setValues` остаётся прежним: отдельного поля alignment в черновике нет.

Без подходящего изображения, при read-only, IME-композиции или загрузке кнопки недоступны. Смена документа/цели во время возврата фокуса отменяет действие. Одно изменение размещения — один Undo; повтор того же значения не создаёт историю. Размер и подпись сохраняются; выравнивается IMG, а не текст подписи. [Формат хранения и ограничения](/ru/images#выравнивание-изображения).

### Форма только для редактирования

```ts
import { createImageForm } from '@morfira-dev/wysiwyg/ui/images';
import type { ImageFormMode } from '@morfira-dev/wysiwyg/ui/images';

const mode: ImageFormMode = 'edit';
const editForm = createImageForm(formHost, editor, { mode });
```

`mode` задаётся при создании: `all` сохраняет прежние Insert/upload/cancel и Enter для вставки; `edit` показывает только поля, обновление и удаление, а Enter обновляет выделенное изображение. Для смены режима пересоздайте форму. Элементы вставки/загрузки/отмены отсутствуют, их handler paths также отклоняют edit mode; он не запускает transport и не отменяет загрузки другого владельца. Отсутствие выделения не превращается в точку вставки.

После восстановления нативного Range заново проверяется тот же фактический IMG. API-замена отменяет старую цель до нового выделения в редакторе; локаль и фокус полей сохраняют черновик. При выключенном сохранении пропорций пустой размер снимается; явный размер — целое число 1–1000, невалидные метаданные отклоняются атомарно. Неизменённая подпись исключается из patch, сохраняя rich-узлы при другом изменении; изменённая подпись остаётся буквальным текстом. См. [контекстные свойства изображения](/ru/contextual-images): это необязательная плавающая обёртка с точным IMG-выделением.

## Маркеры размера изображения

Отдельный `createImageResizeUI` показывает четыре пропорциональных маркера вокруг точно выделенного IMG. Этот модуль не является формой и не подключается пресетами или `createImageForm` автоматически. Нужен установленный `images()`:

```ts
import { createImageResizeUI } from '@morfira-dev/wysiwyg/ui/image-resize';
import type { ImageResizeUIController, ImageResizeUIOptions } from '@morfira-dev/wysiwyg/ui/image-resize';
import '@morfira-dev/wysiwyg/ui/image-resize.css';

const resizeHost = document.createElement('div');
document.body.append(resizeHost);
const options: ImageResizeUIOptions = {
  onError: (error) => console.error('Image resize failed', error),
};
const resizeUI: ImageResizeUIController = createImageResizeUI(resizeHost, editor, options);
const disposeResize = () => {
  resizeUI.destroy();
  resizeHost.remove();
};
```

Host должен быть пустым подключённым HTML-элементом вне `editor.surface`, в том же документе и на обычном viewport-overlay слое. Не помещайте его в transform/paint/clipping-контейнер. `options` содержит только необязательные `label` и `onError`; контроллер возвращает `element`, `refresh()` и идемпотентный `destroy()`. Уничтожение освобождает capture, слушатели, observer/RAF и владение внешним host, не уничтожая редактор.

Клик по изображению выбирает точный IMG. Перетаскивание угла фиксирует пропорцию и меняет только внешние рамку/статус до отпускания: документ и история остаются прежними. Отпускание применяет одну resize-команду с одним Undo; отсутствие изменения не создаёт историю. Escape и отмена указателя отменяют жест. Прокрутка/resize/blur, смена документа или target, read-only и IME также отменяют незавершённый жест. На сфокусированном маркере стрелки меняют размер на 1 px, Shift+стрелка — на 10 px, отдельной операцией истории для каждого шага. Enter/Space не применяют незавершённое перетаскивание.

Подписи, подсказка и текст размеров локализованы через `imageResizeUIMessages` и `ImageResizeUIMessageKey` из того же entry; оформление использует scoped `--mw-*` переменные и явный CSS. Модуль не зависит от стилей сайта документации, не создаёт thumbnail и не загружает изображение дополнительно. Неизвестная пропорция, скрытая/трансформированная или явно искажённая картинка, курсор подписи, целая figure и защищённые/сложные targets не дают маркеров. Углы за clipped-границами скрыты. [Полный пример, границы и демо](/ru/images#перетаскивание-маркеров).

Переменные задаются на внешнем host или его предке. Например, после `resizeHost.className = 'my-resize-overlay'`:

```css
.my-resize-overlay {
  --mw-image-resize-color: #2563eb;
  --mw-image-resize-handle-size: 28px;
  --mw-image-resize-radius: 4px;
  --mw-image-resize-preview: #2563eb12;
  --mw-image-resize-z-index: 1001;
}
```

## Поиск и замена

Контейнеры: `<div id="search-editor"></div>` и `<div id="search-controls"></div>`.

```ts
import { createEditor } from '@morfira-dev/wysiwyg';
import { search } from '@morfira-dev/wysiwyg/plugins/search';
import { createSearchForm } from '@morfira-dev/wysiwyg/ui/search';
import '@morfira-dev/wysiwyg/style.css';
import '@morfira-dev/wysiwyg/ui/forms.css';

const editor = createEditor(document.querySelector<HTMLElement>('#search-editor')!, {
  locale: 'ru', value: '<p>Один пример. Ещё один пример.</p>', plugins: [search()],
});
const form = createSearchForm(document.querySelector<HTMLElement>('#search-controls')!, editor, {
  initialValues: { query: 'пример', wholeWord: true },
});

const draft = form.getValues();
form.setValues({ replacement: 'текст' });

const dispose = () => {
  form.destroy();
  editor.destroy();
};
```

Запрос и параметры — drafts до нажатия «Найти». Если они отличаются от индексированного запроса, кнопки навигации/замены недоступны, чтобы случайно не заменить старые результаты. Enter в запросе запускает поиск с первого совпадения. **Shift+Enter в запросе** переходит к предыдущему совпадению по кругу; для нового запроса сначала выполняет поиск и выбирает последнее совпадение. Подсказка поля локализуется ключом `ui.search.queryKeys`. Enter в поле замены выполняет доступную замену текущего совпадения. IME-подтверждение не перехватывается.

Поиск, переходы и очистка доступны в read-only; замена заблокирована. Команды используют индекс совпадений, а не выделение внутри поля формы. Массовая замена отменяется одним Undo. Удаление UI не очищает состояние поиска, принадлежащее приложению. [Границы буквального поиска](/ru/search).

## Контроллер и значения

Все фабрики возвращают контроллер одного жизненного цикла:

| Поле/метод | Назначение |
| --- | --- |
| `element` | Собственный корневой `HTMLElement`; можно добавить класс или изменить размещение |
| `getValues()` | Независимая копия текущих drafts |
| `setValues(partial)` | Частичное обновление drafts без изменения документа |
| `refresh()` | Обновить UI из актуального состояния редактора/плагина |
| `destroy()` | Снять подписки/обработчики и удалить только собственный UI; повторный вызов допустим |

После уничтожения остальные методы контроллера выбрасывают ошибку; старые DOM-кнопки не выполняют команды. Уничтожение редактора автоматически удаляет формы. При ручном удалении контейнера сначала вызовите `destroy()` — отключение произвольного DOM-узла не является автоматическим lifecycle-сигналом.

| Значения | Поля |
| --- | --- |
| `LinkFormValues` | `href`, `title`, `text`: string; `newTab`: boolean |
| `ImageFormValues` | `src`, `alt`, `caption`, `width`, `height`: string |
| `SearchFormValues` | `query`, `replacement`: string; `caseSensitive`, `wholeWord`: boolean |

Размеры в image drafts — строки полей ввода, а в `ImageValue` — числа. Такая разница сохраняет пустое/ошибочное поле для исправления пользователем; в документ попадают только проверенные значения. `initialValues`, необязательные `label` и `onError` находятся в соответствующих `LinkFormOptions`, `ImageFormOptions`, `SearchFormOptions`.

## Выделение, ошибки и встраивание

По умолчанию формы — встраиваемые немодальные панели с `role="form"`, не вложенные HTML `<form>`. Их можно поставить внутрь формы приложения. Кнопки не отправляют её; Enter в полях обрабатывает локальное действие. Форма изображений также поддерживает `presentation: 'dialog'` и методы `open()`, `close()`, `isOpen()` — см. [окно изображения](/ru/images#окно-вставки-и-редактирования). Готовая панель предоставляет отдельные [всплывающие формы вставки](/ru/editor-ui). Поиск остаётся немодальным и позволяет работать с текстом — см. [поиск и замена](/ru/search).

Ссылки и изображения запоминают настоящий DOM Range перед переходом в поля, включая пустые блоки и обратное выделение. Внешняя замена документа сбрасывает старую цель: сначала выберите место в новом документе. Ввод в поля и смена языка не должны перезаписывать drafts. Поиск использует пересчитанный индекс плагина и не восстанавливает устаревший Range.

Невалидная команда сохраняет документ и введённые поля. Пользователь видит локализованное сообщение; `onError` получает исходную диагностическую ошибку. Не выводите её через `innerHTML`. Формы не обещают полноценный аудит доступности или поддержку всех системных IME.

## Локализация и оформление

```ts
editor.setLocale('en', {
  'ui.links.href': 'Destination URL',
  'ui.images.caption': 'Caption',
  'ui.search.find': 'Find now',
});
```

Словари экспортируются как `linkFormMessages`, `imageFormMessages`, `searchFormMessages` из своих UI-входов; типы ключей — `LinkFormMessageKey`, `ImageFormMessageKey`, `SearchFormMessageKey`. Fallback и приоритет overrides соответствуют [общей локализации](/ru/localization). Явный `options.label` имеет приоритет над словарём.

CSS ограничен `.mw-form`. Он использует общие `--mw-text`, `--mw-muted`, `--mw-surface`, `--mw-border`, `--mw-accent` и необязательные `--mw-form-font-size`, `--mw-form-gap`, `--mw-form-padding`, `--mw-form-radius`, `--mw-form-control-radius`, `--mw-form-error`. На главной и в [playground](/ru/playground) показаны эти же публичные модули; дополнительный demo-engine подключать не требуется.

Для форматирования непустого выделения доступен отдельный [контекстный UI](/ru/contextual-toolbar), а не новый behavior-плагин: `/ui/contextual` и явный `/ui/contextual.css`. Он не устанавливается пресетами и использует существующие команды/историю.

Для курсора или текстового диапазона целиком внутри одной ссылки есть отдельные [контекстные действия ссылки](/ru/contextual-links): `/ui/contextual-link`, явные core/forms/contextual-link CSS, безопасное открытие и изменение/удаление всей ссылки с Undo. Чистый текст без ссылок остаётся у текстовой панели, а смешанный диапазон ссылок и текста внутри одного потока получает действия выбранной части без Open; пресеты этот UI не подключают.

## Контекстные действия таблиц

Отдельная [форма свойств таблицы](/ru/table-properties) через `/ui/table-properties` редактирует ширину/расположение, стили выбранных ячеек, заголовочную первую строку/колонку, буквальную подпись и минимальную высоту строк. Нужны `tables()` и `tableProperties()`, CSS формы подключается явно. Поля «Строка заголовков», «Столбец заголовков» и «Подпись таблицы» входят в общий черновик: Apply отправляет только изменённые значения одним Undo. Объединение через границу заголовка отклоняет весь patch. Новые строковые поля `headerRow`, `headerColumn`, `caption` включены в `getValues()`; заголовки используют `"true"` / пустую строку, подпись сохраняет пробелы. Главная и playground показывают форму рядом с табличными командами; контекстная панель сама её не устанавливает.

Та же форма предоставляет **Отступы ячеек (0–48px)**, **Толщина границ (0–12px)** и **Стиль границ** по [контракту оформления ячеек](/ru/table-properties#отступы-и-границы-ячеек). Строковые черновики `cellPadding`, `cellBorderWidth`, `cellBorderStyle` входят в `getValues()`. Отступ одинаковый для четырёх сторон; толщина, стиль и цвет сбрасываются независимо. Mixed-состояние и отправка только изменённых полей сохраняют остальные значения выбранных ячеек. Стиль — по умолчанию/сброс либо solid/dashed/dotted/double/none. Настройка отдельных сторон и автоматическая установка пресетами не добавляются.


Поле «Минимальная высота строк (1–1000px)» использует строковый черновик `rowMinHeight`: `80px` задаёт минимум всем строкам выбранного логического прямоугольника, включая полный rowspan; пустая строка сбрасывает его. Разные значения строк показываются как смешанные. Контент может сделать строку выше. Полное HTML/JSON сохраняет TR height, но существующие структурные команды пересоздают строки, а прямоугольный clipboard не копирует их высоту.

Явно подключаемая [контекстная панель таблиц](/ru/contextual-tables) добавляет вставку/удаление строк и столбцов, merge/split поверх существующей логической сетки, восстановление native Range и один шаг Undo на команду. Подключите `/ui/contextual-table` и его CSS вместе с `tables()` и CSS таблиц; пресеты не меняются. `getTableSelection(editor, range?)` возвращает наблюдаемый `TableSelectionState`, `registerSelectionHost(host)` задаёт владение внешними контролами, а `tableSelectionChange` — типизированное уведомление экземпляра, не RPC. Гайд описывает spans, недоступные действия, клавиатуру/lifecycle.

## Неизменяющая документ подсветка поиска

`createSearchHighlights(editor)` из `/ui/search-highlights` дополняет форму поиска и требует отдельного `/ui/search-highlights.css`. Это нативные диапазоны CSS Highlight API, а не разметка документа. При отсутствии API поиск продолжает работать без общей подсветки. [Подключение, состояния и очистка](/ru/search-highlights).

## Панель спецсимволов

[Спецсимволы](/ru/special-characters) подключаются отдельно через `createSpecialCharacterUI` из `/ui/special-characters` и явный `/ui/special-characters.css`. Панель не требует плагина: она вставляет буквальный текст в одно действующее текстовое выделение, сохраняет Undo и предоставляет свой небольшой каталог, поиск и клавиатуру. В core и пресеты она автоматически не входит.

## Полноэкранная рабочая область

[Полноэкранный режим](/ru/fullscreen) подключается отдельно через `createFullscreenUI` и `/ui/fullscreen.css`. Он разворачивает выбранную приложением обёртку с настоящим редактором и панелью, без повторного монтажа адаптера. Вход/выход и Escape не добавляют историю; read-only остаётся доступен для просмотра. Режим не модальный, не использует браузерный Fullscreen API и не входит в пресеты автоматически. Внешние контекстные overlay и их слои остаются ответственностью приложения.

## Предпросмотр и сохранение

Необязательный [предпросмотр документа](/ru/preview) показывает отдельный регион чтения с неактивными ссылками и текстовыми заглушками изображений по умолчанию. Автоматические обновления выполняются только для открытого вида; есть и ручное обновление. Редактор не перемонтируется и не меняется.

[Состояние сохранения](/ru/save-state) разделяет headless-контракт сохранения приложения и необязательный локализованный UI. По умолчанию сохранение ручное, autosave включается явно. Успешный старый ответ не подтверждает более новые правки. Демо имитирует задержку и восстановимую ошибку без сети и хранения. Пресеты автоматически не устанавливают эти модули.

Форма свойств таблицы также включает нативные select `cellTextAlign` и `cellDirection`: выравнивание текста и LTR/RTL применяются к выбранным ячейкам, а не рекурсивно к их абзацам. Сброс восстанавливает наследование; собственные стили потомков сохраняются. [Пример, смешанные значения и ограничения](/ru/table-properties#выравнивание-и-направление-текста-ячеек).


## Печать и навигация по заголовкам

[Печать](/ru/print) — отдельный `/ui/print` с обязательным CSS и локализованными Print/Cancel-контролами. Явный запрос открывает настоящий диалог браузера для проверенного снимка без сайта и панелей; изображения остаются текстом, шрифты системные. Это не PDF-конвертер и не гарантия точной пагинации. Снимок освобождается по событию завершения, отмене или уничтожению.

[Оглавление](/ru/outline) — отдельный `/ui/outline` с CSS, ограниченным списком обычных заголовков и нативными кнопками перехода. Оно не добавляет якоря или IDs в документ. Обе возможности доступны в read-only, не входят в пресеты и показаны на главной в «Печать и оглавление».

[Перетаскивание текста](/ru/text-drop) — поведение `/plugins/text-drop`, которому не нужна UI-обёртка или CSS. Полная демка явно подключает его и позволяет подготовить выделенный rich-фрагмент, перенести его мышью, повторно выделить после Undo или использовать обычные Cut/Copy/Paste с клавиатуры. Presets не меняют drop автоматически; изображения/файлы и semantic-узлы сохраняют собственные границы.

Контекстные свойства изображения принимают также всю простую figure и каретку в обычной подписи, сохраняя исходный Range. Смешанные диапазоны со ссылками внутри одного текстового потока редактируют только выделенные части; разные URL не подставляются в форму автоматически.
