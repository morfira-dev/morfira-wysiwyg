# Архитектура и вес

## Workspaces

| Workspace | Ответственность |
| --- | --- |
| `packages/core` | Схема документа, проверка HTML/JSON, Selection/Range, история, транзакции, lifecycle плагинов и необязательная панель |
| `packages/plugins` | Собственная сетка таблиц, структурные операции, выделение и контекстный UI |
| `packages/vue`, `packages/react`, `packages/svelte` | Привязки фреймворков и очистка ресурсов |
| `packages/wysiwyg` | Публичные subpath exports |
| `apps/docs` | Локальная документация на русском и английском |
| `specs`, `skills/morfira-sdd` | Спецификации поведения и правила разработки |

## Граница runtime

У ядра и плагинов нет runtime-зависимостей. Фреймворки — peers адаптеров, инструменты сборки, документации и тестов — dev-зависимости. Корневой публичный импорт экспортирует только ядро; таблицы и адаптеры подключаются отдельными путями.

Редактирование реализовано собственным TypeScript-кодом со стрелочными const-функциями. JSON версии 1 содержит семантические узлы. Инертный HTML-шаблон преобразуется в разрешённое дерево, затем DOM создаётся из проверенных значений. Браузерный contenteditable обрабатывает нативный ввод, явные Selection/Range-операции — команды. Ограниченная история хранит ревизии с закладками выделения. Состояние и очистка плагинов принадлежат экземпляру.

Это ранний движок: история снимков проста и ограничена, но не является журналом совместного редактирования. Производительность больших документов, браузерная нормализация блоков и сложный composition требуют отдельной проверки. Маленький вес не означает полного функционального паритета.

## Измерение размера

`pnpm run build` создаёт `size-report.json`: minified JS, gzip, Brotli; CSS отдельно. Учитываются все runtime-чанки, исключены декларации/maps. Svelte-компонент для измерения компилируется и минифицируется: вес не сводится к маленькому entry-файлу. Фреймворки не учитываются.

Ориентиры: core JS 200000 байт, table JS 150000, адаптер 10000. Размеры считаются по пакетам; сжатый размер — сумма реальных сжатых выходных файлов. Новым плагинам нужны независимые бюджеты.

## Контракты исходников

`pnpm run check:project` проверяет стрелочные реализации, MIT в пакетах и отсутствие runtime-зависимостей ядра/плагинов. SDD-контракты находятся в `specs/editor.md` и `specs/tables.md`; перед изменениями читайте `AGENTS.md`. Изменения API/формата документа требуют SemVer и обновления обеих версий документации.

Команды изображений подключаются через `/plugins/images` вне графа ядра. `images.js` измеряет этот вход и общие чанки отдельно; `plugins.js` по-прежнему измеряет табличный вход и его чанки. Для каждого входа действует порог 150000 байт minified JS — существующий ориентир дополнительных модулей. Общие чанки учитываются в каждом независимо загружаемом входе.
