# Списки и форматирование

[Попробовать на главной](/#editor): выбери пример **«Списки и вложенность»** и нажми «Загрузить пример». Пример заменяет документ и сбрасывает историю.

## Работа со списками

Выделение нескольких абзацев превращается в один список. Смена типа или отключение списка затрагивает выбранные пункты: соседние пункты и подсписки сохраняются.

```ts
editor.format('list', 'bullet'); // Маркеры
editor.format('list', 'ordered'); // Нумерация
editor.format('list', false); // Убрать список у выбранных пунктов
editor.format('indent', 1); // Вложить под предыдущий пункт
editor.format('indent', -1); // Поднять на один уровень
```

Для отступа выбери один пункт или последовательный диапазон соседей одного уровня. Первый пункт нельзя вложить без предыдущего соседа. Максимум — восемь уровней. При подъёме пункта его следующие вложенные соседи остаются под ним: порядок текста сохраняется. Невалидная команда откатывается целиком. Каждая операция участвует в undo/redo. Отключение списка у вложенного пункта поднимает его на один уровень.

| Клавиша | В списке |
| --- | --- |
| Enter | Разбить пункт в позиции курсора; выделение внутри одного тела заменяется, последующие тела переходят в новый пункт |
| Enter в простом пустом пункте | Подняться на уровень; на верхнем уровне выйти в абзац. Пустой блок среди других тел делится внутри структуры списка |
| Shift+Enter | Перенос строки внутри пункта |
| Backspace в начале | Внутри многоблочного пункта соединить с предыдущим телом; на первом теле — с предыдущим пунктом. Первый корневой пункт выходит из списка, первый вложенный поднимается на уровень; тела и ветки сохраняются |
| Delete в конце тела | Соединить со следующим телом; после последнего — с первым телом следующего подходящего пункта |
| Tab / Shift+Tab | Увеличить/уменьшить вложенность вне таблиц |

В ячейках таблицы Tab сохраняет навигацию по ячейкам. Вложенность списка внутри ячейки меняется кнопками панели. Shift+Enter и обычный ввод сохраняют текст внутри пункта. Подсписок после позиции Enter переходит в новый пункт вместе с хвостом содержимого.

Во время composition таблицы пропускают Tab/Shift+Tab/Escape для управления кандидатом IME: курсор не переходит в другую ячейку и новая строка не добавляется. После завершения composition обычная табличная навигация возобновляется.

## Абзацы, заголовки и ввод IME

В обычном абзаце Enter разбивает текст в позиции курсора, сохраняя оформление. В середине заголовка получается второй заголовок; в конце — новый абзац. Enter в пустом заголовке превращает его в абзац. Shift+Enter вставляет перенос строки внутри блока. Выделенный текст внутри одного блока сначала заменяется.

Backspace в начале и Delete в конце объединяют соседние абзацы/заголовки одного контейнера. Сохраняются оформление левого блока и курсор в точке соединения. Удаление на границе не переносит текст через таблицу, изображение, список или другую ячейку. Для списков действуют правила из таблицы выше и ограниченный контракт [выделений между телами и пунктами](/api#выделения-и-границы-пунктов-списка). Все поддержанные структурные операции участвуют в undo/redo.

При активном вводе через IME браузер управляет промежуточным текстом. Ядро не запускает структурные команды и не записывает каждый вариант кандидата в историю. Markdown shortcuts и меню подсказок не перехватывают подтверждение кандидата. После завершения composition результат отменяется одной операцией. Включение read-only отменяет незавершённый ввод; внешняя замена документа остаётся приоритетной. Эти сценарии проверены контролируемыми событиями браузера, но настоящие окна кандидатов и мобильные клавиатуры требуют отдельной ручной проверки.

Попробовать клавиши можно в редакторе на главной или в [демо](/playground); отдельный модуль подключать не нужно.

## Панель и состояния

Стандартная панель содержит оба типа списка, отступы и очистку строчного форматирования. Undo/redo доступны только при наличии истории. Смешанное выделение показывает `aria-pressed="mixed"`; нажатие включает формат у всего выделения.

```ts
const dispose = createToolbar(toolbarHost, editor, [
  { label: 'Полужирный', text: 'B', format: 'bold' },
  {
    label: 'Увеличить отступ', text: '⇥', format: 'indent', value: 1,
    enabled: (instance) => Boolean(instance.getFormats().canIndent),
  },
  {
    label: 'Отменить', text: '↶', run: (instance) => instance.undo(),
    enabled: (instance) => instance.canUndo(),
  },
], { label: 'Форматирование документа' });
```

Tab входит в панель через одну доступную кнопку; ←/→ и Home/End перемещаются между доступными кнопками, Enter/Space запускают команду, Escape возвращает выделение в редактор. Закладки DOM сохраняют каретку и в пустых пунктах. Вызови `dispose()` до уничтожения редактора; отключённые от панели кнопки перестают выполнять команды.

`getFormats()` возвращает форматы в начале выделенного текста, `mixed` — имена неодинаковых форматов, `listDepth` — глубину, `canIndent`/`canOutdent` — доступность операций для диапазона. Выравнивание читается из текущего блока. Форматирование заголовка внутри пункта сохраняет `li` и соседние внутренние абзацы.

`editor.format('clear', true)` убирает строчные метки, ссылки и span-оформление только у выделенного текста. Структура списков, блоки, изображения и выравнивание остаются. При пустом выделении команда ничего не меняет.

## Вставка нескольких блоков в пункт

В новом локальном пути `editor.insertHTML` и HTML-буфер заменяют выделение двумя и более обычными абзацами/заголовками. Они становятся телами сохранённого пункта, а не новыми пунктами списка. Первый блок соединяется с невыделенным началом, сохраняя исходный левый тег и атрибуты; последний принимает строчный остаток справа. Средние и последний входящие блоки сохраняют собственные теги и атрибуты. Невыделенные тела и хвостовые вложенные списки остаются после результата.

Попробуй **«Содержимое пункта: Несколько блоков» → «Загрузить пример с блоками» → «Выделить пункты» → «Заменить несколькими блоками»**. Для замены внутри одного пункта есть **«Выделить блоки пункта»**, а внутри одного абзаца — **«Выделить текст одного блока»**. Поле **«HTML из нескольких блоков»** редактирует входящий фрагмент. Undo должен восстановить исходное выделение; сценарии пока не запускались.

Тот же многоабзацный фрагмент можно вставить в схлопнутый курсор внутри поддержанного пункта. В демо выбери **«Позиция вставки блоков» → «Начало блока», «Внутри слова» или «Конец блока» → «Курсор для вставки блоков» → «Заменить несколькими блоками»**. Средняя позиция находится внутри жирного слова первого тела. Начало исходного блока соединяется с первым входящим содержимым, остаток — с последним; соседние тела и вложенные ветки сохраняются. Прямое строчное тело получает `p`, если вставляемая последовательность требует блочных соседей. Новые `li` не создаются. Undo возвращает исходную позицию курсора; сценарии пока не запускались.

Одиночные обычные заголовок и цитата имеют отдельные пути, описанные ниже. Семантические входящие блоки, смешанные строчно-блочные фрагменты, списки и таблицы остаются за границей нового многоабзацного пути. Нативный ввод, строчная вставка и остальные одиночные структурные корни сохраняют прежние обработчики. Полные правила и отказ до изменения документа описаны в [API](/api#выделения-и-границы-пунктов-списка).

Для другого одиночного структурного корня, например таблицы, внутри одного исходного тела сохраняется прежний общий обработчик; новый путь не определяет его поведение заново.

## Одиночный заголовок внутри пункта

Обычный `h1`–`h6` вставляется отдельным телом пункта с собственным тегом и разрешёнными атрибутами. Исходное начало остаётся отдельным телом перед ним; остаток конечного исходного тела — отдельным телом после него с прежним тегом/атрибутами. Прямое строчное содержимое получает `p`. Курсор оказывается перед остатком справа, пустые края сохраняют placeholder `br`. Новые `li` не создаются, соседние тела и ветки сохраняются. В отличие от многоабзацной вставки, обёртка входящего заголовка не снимается.

Загрузи пример списка, выбери позицию и нажми **«Курсор для вставки блоков»** либо используй кнопки выделения, затем **«HTML одиночного заголовка → Вставить заголовок»**. Например, `Аль|фа` превращается в `<p>Аль</p><h2>Заголовок</h2><p>фа</p>`. Одиночный семантический заголовок отклоняется до изменения документа. Этот локальный сценарий, история и точная позиция курсора ещё не проверены запуском.

## Цитата внутри пункта

Один обычный `blockquote` вставляется отдельным блоком: исходное начало остаётся перед цитатой, а отдельное тело после неё получает исходный остаток и его тег/атрибуты. Для прямого строчного пункта создаются края `p`. Курсор оказывается в начале правого остатка. Теги и атрибуты цитаты, соседние тела и вложенные ветки сохраняются; новые пункты списка не создаются. Пустые края, пустая строчная цитата и пустые абзацы/заголовки внутри неё получают редактируемые placeholders.

Входящая цитата может содержать либо строчный текст с разрешёнными стилями/ссылками/изображениями, либо обычные абзацы и заголовки. Семантическая обёртка цитаты или её блочных детей, смесь строчного и блочного содержимого, вложенные цитаты, списки, таблицы и другие структуры отклоняются до изменения документа. Строчные семантические узлы сохраняются после проверки схемы.

Для примера загрузи исходный список, выбери позицию курсора либо выдели текст/пункты, затем **«HTML цитаты → Вставить цитату»**. В поле по умолчанию находятся абзац и заголовок внутри цитаты. Обычный ввод в правом остатке и Undo доступны. Тесты, сборки и новые замеры отложены.

### Повторная вставка рядом с цитатой

Нажми **«Загрузить пример повторной вставки» → «Курсор после существующей цитаты»**, затем последовательно **«Вставить цитату» → «Вставить заголовок» → «Заменить несколькими блоками»**. Исходная цитата, последующие тела и вложенная ветка сохраняются без перезагрузки; каждый шаг имеет отдельный Undo. Кнопка **«Курсор перед существующей цитатой»** позволяет вставлять с другой стороны. Загрузка заменяет документ.

Только новый путь блочной API/clipboard-вставки рассматривает обычные исходные цитаты как целые сохраняемые узлы. Для вставки снаружи концы выделения должны быть в обычных текстовых телах; отдельный профиль теперь поддерживает пересечение или полное покрытие одной или нескольких обычных цитат внутри того же пункта. Позиция `li`, выбирающая целую цитату, тоже является барьером. Неподдержанная или семантическая цитата отклоняет операцию даже вне выделения. Нативные операции на границах, строчная и одноабзацная вставка не расширены. Полное редактирование цитат и подтверждённая совместимость с браузерами этим этапом не заявляются; подробный контракт — в [API](/api#выделения-и-границы-пунктов-списка).

### Блочная вставка внутри одной цитаты

Нажми **«Загрузить пример вставки внутри цитаты»**, затем **«Курсор внутри цитаты»** или **«Выделить блоки внутри цитаты»**. Кнопки **«Заменить несколькими блоками»** и **«Вставить заголовок»** вставляют обычные `p`/`h1`–`h6` внутри того же фактического `blockquote`. Его обёртка и атрибуты, невыделенные дочерние блоки, внешние тела пункта и вложенный список сохраняются. Загрузка примера заменяет документ.

Для нескольких входящих блоков начало соединяется с первым, остаток — с последним; одиночный заголовок остаётся отдельным телом между началом и остатком. Строчная исходная цитата получает обёртку `p` вокруг своего текстового тела. Курсор ставится перед остатком, пустые тела остаются редактируемыми, Undo возвращает точный исходный курсор или направление выделения.

Поддержаны курсор и диапазон между обычными блоками **одной** цитаты. Переход между разными цитатами относится к отдельному пути ниже. Новая вложенная цитата, семантические блочные корни, исходные изображения и неподдержанные структуры отклоняются атомарно. Вставка строчного текста/одного абзаца и нативные операции на границах сохраняют прежние правила. Это ограниченный путь вставки; тесты, сборки, типизация и свежие размеры пока не проверялись.

### Блочная замена через одну цитату

Нажми **«Загрузить пример пересечения цитаты»**, выбери **«Выделить снаружи внутрь цитаты»**, **«Выделить из цитаты наружу»** или **«Выделить через целую цитату»**, затем **«Заменить несколькими блоками»**, **«Вставить заголовок»** или **«Вставить цитату»**. Для сравнения направлений загружай пример заново; загрузка заменяет документ.

Пример показывает одну цитату; тот же ограниченный профиль поддерживает несколько обычных цитат внутри одного пункта. Каждая входящая обёртка сохраняет тег и разрешённые атрибуты на уровне пункта, включая первый абзац многоабзацного payload. Невыделенный край исходной цитаты сохраняет фактическую обёртку и остаётся цитатой; полностью выбранная цитата удаляется. При входе в цитату создаётся редактируемый пустой абзац перед её остатком, курсор — в нём. При выходе наружу остаток сохраняет отдельное тело, курсор — в его начале. Другие тела и вложенная ветка сохраняют порядок. Концы в разных цитатах и несколько покрытых цитат разрешены в одном пункте либо в допустимом диапазоне соседних пунктов по профилю ниже; переходы между уровнями и внутрь веток блокируются. Нативные и строчные пути не меняются. Точное восстановление выделения, история и совместимость с браузерами **не проверены**; тесты написаны, но не запускались.

### Блочная замена через несколько цитат

Новый пример **«Загрузить пример нескольких цитат»** содержит три цитаты, промежуточное тело и вложенную ветку. Выбери **«Выделить между цитатами»**, **«Выделить снаружи до последней цитаты»**, **«Выделить из первой цитаты наружу»** или **«Выделить через все цитаты»**, затем используй те же кнопки вставки. Между двумя частично выбранными цитатами начало первой и остаток последней остаются в своих фактических обёртках; полностью покрытая средняя цитата удаляется. Если справа цитатный остаток, перед ним создаётся обычный абзац с курсором. Проверяется **каждая** затронутая цитата, в том числе удаляемая целиком: исходные изображения, семантические блочные корни и вложенные структуры отклоняют всю операцию до изменения документа. Для сравнения направлений загружай пример заново; история и совместимость с браузерами пока не проверены запуском.

### Цитаты в соседних пунктах

Нажми **«Загрузить цитаты в соседних пунктах»**, выбери **«Выделить цитаты соседних пунктов»**, **«Выделить до цитаты последнего пункта»**, **«Выделить из цитаты до внешнего остатка»** или **«Выделить через цитаты всех пунктов»**, затем используй **«Заменить несколькими блоками»**, **«Вставить заголовок»** или **«Вставить цитату»**. Загрузка заменяет документ; загружай пример заново для сравнения направлений.

Блочная API/clipboard-вставка через обычные цитаты допускает последовательные пункты **одного родительского `ul`/`ol`**. Фактический первый пункт и его невыделенное начало сохраняются. Частичный остаток последнего пункта, следующие за ним тела/невыделенные цитаты и конечные вложенные списки переносятся в первый пункт фактическими узлами, в исходном порядке; остальные выбранные пункты, полностью покрытые цитаты и промежуточные тела удаляются. Входящие обёртки остаются отдельными блоками на уровне первого пункта. Если справа цитатный остаток, перед ним создаётся новый обычный `p` с `br` и курсором в начале; иначе курсор находится в начале внешнего тела с остатком. Прямой строчный край пункта получает обёртку `p` с переносом исходных дочерних узлов.

Каждая затронутая цитата проверяется целиком, включая цитаты удаляемых средних пунктов: исходные изображения, семантические блочные корни и вложенные структуры отклоняют всю операцию до изменения документа. Первый и промежуточные пункты не могут содержать вложенные списки; у последнего допустимы только полностью невыделенные хвостовые ветки. Разные родительские списки, уровни и концы внутри веток, а также позиции `li`, разрешающиеся в целую цитату, остаются барьерами. Нативный ввод, строчная/одноабзацная вставка и обычная замена без затронутых цитат сохраняют прежние пути. Сценарии точного выделения, Undo/Redo, переноса узлов и read-only **написаны, но не запускались**; сборки, типизация и свежие размеры также отложены.

## Границы текущей версии

**Новый локальный этап пока не проверен запуском.** Один пункт может содержать несколько обычных `p`/`h1`–`h6`, за которыми следуют вложенные списки. Замена между телами одного пункта и соседними пунктами сохраняет невыделенные блоки; Enter переносит последующие тела в новый пункт, а Delete/Backspace соединяют соседние тела. Подробные ограничения, включая семантические тела и структурные payload, описаны в [API](/api#выделения-и-границы-пунктов-списка). В демо открой **«Выделение пунктов списка» → «Содержимое пункта: Несколько блоков» → «Загрузить пример с блоками»**. Затем попробуй **«Выделить блоки пункта»** или **«Выделить пункты»** и замену; **«Курсор перед Delete»** готовит внутреннюю границу. Для первого тела выбери **«Сценарий Backspace» → «Загрузить пример Backspace» → «Курсор перед Backspace»** и нажми Backspace: попробуй объединение, выход корневого и подъём вложенного пункта. Загрузка заменяет документ. Предыдущий пункт должен иметь поддержанное тело. Режим «Вложенная ветка перед другими» показывает подъём из непоследней ветки: ранние ветки остаются у родителя; под поднятым пунктом идут его собственные ветки, следующие пункты исходного списка и затем поздние ветки родителя. Типы, атрибуты и порядок содержимого сохраняются без склеивания. Переносимые поздние ветки проходят проверку обычного списка с поддержанными непосредственными пунктами до изменения документа. Семантические и сложные формы остаются атомарными барьерами. Тесты, сборки и новые замеры веса отложены. Нет обещания одинаковой нормализации произвольного HTML из офисных редакторов. Реальная IME/mobile-проверка и полный аудит доступности остаются в плане. Цвет текста и редактирование ссылок описаны в [отдельном руководстве](/styling).

Полужирный, курсив, подчёркивание, зачёркивание, строчный код и индексы используют локальное проверенное преобразование, когда выделение остаётся в одном обычном абзаце или заголовке. Остальные блоки и их DOM-слушатели сохраняются. Для сложных и межблочных выделений работает общий путь. Повторное включение уже унаследованного стиля — пустая операция; контракты undo/redo и проверки HTML/JSON сохраняются. Настройка приложения для этого не требуется.
