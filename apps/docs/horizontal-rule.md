# Разделитель

[Попробовать на главной](/#editor) или [в стенде возможностей](/playground): открой **«Разделитель»**, нажми **«Загрузить пример разделителя»**, затем **«Разделитель» на панели форматирования**. Загрузка заменяет документ, сбрасывает историю и ставит курсор внутри полужирного слова. После команды можно сразу продолжать печатать; один Undo возвращает исходный блок и выделение.

## Подключение

Готовые `standard` и `extended` пресеты включают команду по умолчанию. `horizontalRule: false` исключает её из выбранной конфигурации; для исключения кода из бандла используй выборочные импорты вместо статического графа готового пресета. `minimal` и ядро плагин не подключают.

Для явной композиции:

```ts
import { createEditor } from '@morfira-dev/wysiwyg';
import { horizontalRule, horizontalRuleCommands } from '@morfira-dev/wysiwyg/plugins/horizontal-rule';
import '@morfira-dev/wysiwyg/style.css';

const editor = createEditor(host, {
  plugins: [horizontalRule()],
  value: '<p>Alpha <strong>one</strong> tail</p>',
});
const rules = horizontalRuleCommands(editor);
editor.setSelection(7);
if (!rules.getState().disabled) rules.insert();
```

Это отдельный плагин без runtime-зависимостей и обязательного CSS. Импорт безопасен при SSR; создание редактора выполняется в браузере. Плагин не импортируется ядром. Установленная готовая панель показывает кнопку только при наличии плагина. Собственная внешняя кнопка должна сохранять и восстанавливать актуальное выделение редактора.

## Поведение и API

`horizontalRuleCommands(editor)` возвращает `insert(): void` и `getState(range?: Range): HorizontalRuleState`. Состояние — новый снимок `{ disabled: boolean }`; read-only, composition, отсутствующее или неподдержанное выделение блокируют вставку. Недоступная команда не меняет документ, выделение и историю. Получение API без установленного плагина и использование сохранённого API после уничтожения выбрасывают ошибку.

Для внешнего интерфейса `getState(savedRange)` может прочитать доступность по сохранённому нативному Range. Чтение не меняет фактическое выделение, DOM, историю и уведомления; read-only и composition по-прежнему учитываются. Это не разрешение на вставку: `insert()` всегда проверяет текущее нативное выделение. Перед действием собственная кнопка должна восстановить актуальный диапазон. Готовая панель делает это сама.

Поддержаны курсор и диапазон целиком внутри **одного обычного `p` или `h1`–`h6` непосредственно в корне редактора**. Выделенный текст заменяется последовательностью: исходное начало → обычный `<hr>` → остаток. Оба края сохраняют исходный тег, атрибуты и оставшееся строчное форматирование; пустой край получает редактируемый `<br>`. Соседние блоки остаются на месте.

**Заголовок остаётся заголовком с обеих сторон**, даже при пустом остатке. Чтобы продолжить обычным абзацем, выбери «Абзац» в панели форматирования. Курсор после вставки находится в начале фактического остатка, после HR, а не на самом разделителе. Курсор без выделения сохраняет действующие настройки набираемого текста. При замене диапазона устаревшие настройки прежнего курсора не восстанавливаются, даже если текстовая позиция совпала.

Успешная вставка — одна транзакция, одно уведомление об изменении и один шаг Undo. Undo восстанавливает содержимое и направление выделения; Redo — разделитель и курсор в остатке. Внешняя замена документа сохраняет обычный контракт API.

## Формат и ограничения

Сохраняется обычный HR схемы v1 без атрибутов, ролей, собственного маркера и UI-узлов. HTML/JSON сохраняют разделитель и без этого плагина. Markdown shortcut для HR остаётся независимым способом ввода.

Не поддержаны выделения между блоками, позиции непосредственно на границе корня, списки, цитаты, таблицы, подписи, `pre` и блоки с owning-маркерами `data-mw-node`. Также недоступен исходный блок с любым `img`, включая изображение вне выделения: первая версия не клонирует сохранённые ресурсные узлы ради разделения текста. Любой owning-семантический потомок тоже блокирует весь исходный блок, даже вне выделения. Это ограниченная структурная команда; пример не обещает аналогичное поведение произвольного `insertHTML('<hr>')`.

Цвет и вертикальные отступы содержимого настраиваются через scoped CSS-переменные `--mw-horizontal-rule-color` и `--mw-horizontal-rule-spacing`; по умолчанию используются цвет границы редактора и `1em`. Эти стили ядра применяются и к HR, созданному Markdown shortcut.

У нативного HR есть семантика разделителя; команда не делает его фокусируемым и не добавляет интерактивных украшений. Полная доступность навигации по разделителям этим не заявляется. Актуальные выполненные проверки и размеры смотри в [дорожной карте](/roadmap#проверки-и-ограничения).
